12 投资组合回测

本章先给出分析和比较投资策略所需的符号与框架。投资组合回测常被视为寻找“最佳策略”的过程，至少也要找到一种能够稳定盈利的策略。然而，如果反复搜索而缺少约束，这一漫长过程很容易让人把偶然结果误认为稳健策略。以下两篇相继发表的论文都提醒读者警惕数据窥探；这一问题与 \(p\) 值操纵密切相关。两种情形的共同点是：研究者反复挖掘同一批数据，直到得到自己想要的结果。

Fabozzi and Prado (2018) 指出，公开发表的通常只是“有效”的策略，而背后可能已有成千上万种方案接受过检验。从这些结果中挑出最亮眼的异常值，也就是唯一看似奏效的策略，投入真实交易后往往令人失望。类似地，R. Arnott, Harvey, and Markowitz (2019) 给出了一系列原则和防护措施，帮助分析师避免回测错误。其中最危险的或许是假阳性（误报）：策略往往经过选择性筛选，只在某个非常特殊的设定下表现优异，却很可能在实盘中失效。

除投资组合构建方面的建议外，R. Arnott et al. (2019) 还提醒投资者，不要盲目买入与学术因子挂钩的智能贝塔（smart beta）产品。对这类产品不应抱有过高预期，否则很容易失望。文章的另一项重要结论是，经济周期会显著影响因子收益：相关性可能迅速变化，而在经济大幅下行时，回撤还会被放大。

回测远比表面上复杂。一个看似微小的错误，就可能制造出一套貌似出色的投资策略。本章将给出严谨的回测流程，讨论常见注意事项，并通过一个较为完整的示例加以说明。

12.1 设定流程

我们考虑一个包含三个维度的数据集：时间 \(t=1,\dots,T\)、资产 \(n=1,\dots,N\) 和特征 \(k=1,\dots,K\)。其中一个属性必须是资产 \(n\) 在时点 \(t\) 的价格，记为 \(p_{t,n}\)。有了价格，就能直接计算算术收益率 \(r_{t,n}=p_{t,n}/p_{t-1,n}-1\)，也可以据此构造其他经验性的盈利指标。为简化讨论，假设各时点等间隔排列，例如 \(t\) 表示交易日或月份。若每个时点 \(t\) 都有全部资产的数据，那么数据集共有 \(I=T\times N\) 行。

首先把时间区间分为样本外期和初始缓冲期。初始缓冲期用于训练第一次构建投资组合所需的模型，其长度由训练窗口决定。训练窗口通常有两种设定：固定窗口，常取 2 至 10 年；或扩展窗口。固定窗口随时间向前滚动，只保留最近的数据。扩展窗口则使用截至当时的全部历史数据，因此样本规模会不断增加。扩展窗口可能带来可比性问题，因为回测初期可用的信息远少于后期。此外，是否应纳入收益率和特征的完整历史，本身也存在争议。支持者认为，完整历史能让模型经历更多种市场状态；反对者则认为，过旧的数据已经失去代表性，不仅无助于刻画当前或近期未来的波动，还可能误导模型。

下文采用滚动的固定训练窗口，如图 12.1 所示。

图 12.1：使用滚动窗口进行回测。第一个回测期的训练集就是初始缓冲期。

回测中有两个关键的设计选择：投资组合的再平衡频率，以及标签对应的预测期。两者不必完全相同，但必须相互协调。例如，用未来 12 个月收益率作为标签来捕捉较长期趋势，再按月或按季度调整持仓，是较为合理的做法；反过来，用月度收益训练短期信号，却长期持有而不调整，就显得不太一致。

这两个选择会直接决定回测的时间切分方式。记：

  • \(\Delta_h\) 为两次再平衡之间的持有期，以天或月计；
  • \(\Delta_s\) 为所需训练窗口的长度，以天或月计，不考虑横截面上的资产数量；
  • \(\Delta_l\) 为计算标签所覆盖的预测期，以天或月计。

因此，要取得所需长度的可用训练样本，原始历史区间必须覆盖 \(\Delta_s+\Delta_l\)。在任一决策时点 \(t\)，训练特征最晚只能取到 \(t-\Delta_l\)，这样最后一个训练标签才恰好能用截至 \(t\) 的数据计算。图 12.2 用红色标出了不能纳入训练的危险区间 \((t-\Delta_l,t]\)。若某条观测的时间索引为 \(s\)，且 \(s \in (t-\Delta_l,t]\)，其标签终点便满足 \(s+\Delta_l>t\)，因为标签覆盖区间 \([s,s+\Delta_l]\)。也就是说，在时点 \(t\) 使用这条观测，就必须提前知道未来结果，从而产生前视偏差。

图 12.2：滚动训练样本中的时间边界。

12.2 将信号转化为投资组合权重

5 至 11 章介绍的预测工具，首先产生的是一个信号：它应当包含有关资产未来收益率的信息。要把信号转化为实际投资决策，可以采用多种方法；关于如何把机器学习工具纳入这一过程，可参阅 Snow (2020)。

投资组合构建至少包含两个环节，信号可以用于其中任一环节，也可以同时用于两者。不过，如果资产选择和权重分配都完全依赖同一信号，就等于把很大筹码押在预测上，只有在对预测把握很高时才宜采用。

第一步是资产选择。即使模型能为大量资产生成预测，也没有必要持有全部资产。对于只做多的组合，利用信号剔除预计表现不佳的资产尤其合理。很多投资策略会预先规定持仓数量，因此最直接的做法，就是保留预测最有利的资产、舍弃其余资产。资产定价研究经常使用这种简单方法：按某项基础特征的分位数组建排序投资组合；如果不同分位数组合的收益表现明显不同，例如高分位数组合平均收益较高、低分位数组合较低，就说明该特征可能具有定价信息。

这种排序也是检验信号有效性的一种简便方法。若按照信号排名构造 \(Q\) 个组合 \(q=1,\dots,Q\)，那么组合的样本外表现理应随 \(q\) 呈单调变化。严格检验单调性需要同时考察全部组合，例如 Romano and Wolf (2013) 的方法；实践中则常只比较两个极端组合。如果第 1 组与第 \(Q\) 组的收益差异显著，说明信号具有价值。若允许卖空，以相等名义金额做多一个极端组合并做空另一个极端组合，便可构造美元中性的多空策略。

第二步是权重分配。如果资产选择已经依赖预测信号，权重方案通常越简单越好。等权组合一向很难被稳定超越（参见 DeMiguel, Garlappi, and Uppal (2009)）；Plyakha, Uppal, and Vilkov (2016) 表明，相比市值加权组合尤其如此。更复杂的方案包括等风险贡献（Maillard, Roncalli, and Teiletche (2010)）和带约束的最小方差配置（Coqueret (2015)）。这两类方法只需要资产收益率的协方差矩阵，不必估计预期收益率向量。

为完整起见，下面给出 Coqueret (2015) 的一个推广形式，即通用的带约束二次规划： \[\begin{equation} \tag{12.1} \underset{\textbf{w}}{\text{min}} \ \frac{\lambda}{2} \textbf{w}'\boldsymbol{\Sigma}\textbf{w}-\textbf{w}'\boldsymbol{\mu} , \quad \text{s.t.} \quad \begin{array}{ll} \textbf{w}'\textbf{1}=1, \\ (\textbf{w}-\textbf{w}_-)'\boldsymbol{\Lambda}(\textbf{w}-\textbf{w}_-) \le \delta_R,\\ \textbf{w}'\textbf{w} \le \delta_D, \end{array} \end{equation}\]

目标函数左侧就是常见的均值—方差优化，右侧则施加了三个约束。23 第一个是预算约束，即所有权重之和为 1。第二个约束通过对角矩阵 \(\boldsymbol{\Lambda}\) 惩罚目标权重相对当前配置 \(\textbf{w}_-\) 的变化，以限制换手和交易成本。这一点非常重要：投资组合通常不是从零开始建立，而是在现有持仓基础上再平衡。上式中，当前权重为 \(\textbf{w}_-\)，目标权重为 \(\textbf{w}\)，因此 \(\textbf{w}-\textbf{w}_-\) 表示需要调整的权重。二次项 \((\textbf{w}-\textbf{w}_-)'\boldsymbol{\Lambda}(\textbf{w}-\textbf{w}_-)\) 是按 \(\Lambda_{n,n}\) 加权的权重变化平方和，可为交易成本较高、流动性较差的资产设置更大惩罚。\(\delta_R\) 越小，目标权重越不能偏离 \(\textbf{w}_-\)，因而换手率越低。最后一个约束通过投资组合的 Herfindahl-Hirschman 指数控制分散化：\(\delta_D\) 越小，持仓越分散。

记可投资范围内共有 \(N\) 项资产，则 (12.1) 的拉格朗日函数为：

\[\begin{equation} \tag{12.2} L(\textbf{w})= \frac{\lambda}{2} \textbf{w}'\boldsymbol{\Sigma}\textbf{w}-\textbf{w}'\boldsymbol{\mu}-\eta (\textbf{w}'\textbf{1}_N-1)+\kappa_R ( (\textbf{w}-\textbf{w}_-)'\boldsymbol{\Lambda}(\textbf{w}-\textbf{w}_-) - \delta_R)+\kappa_D(\textbf{w}'\textbf{w}-\delta_D), \end{equation}\]

其一阶条件为 \[\frac{\partial}{\partial \textbf{w}}L(\textbf{w})= \lambda \boldsymbol{\Sigma}\textbf{w}-\boldsymbol{\mu}-\eta\textbf{1}_N+2\kappa_R \boldsymbol{\Lambda}(\textbf{w}-\textbf{w}_-)+2\kappa_D\textbf{w}=0,\] 由此得到 \[\begin{equation} \tag{12.3} \textbf{w}^*_\kappa= (\lambda \boldsymbol{\Sigma}+2\kappa_R \boldsymbol{\Lambda} +2\kappa_D\textbf{I}_N)^{-1} \left(\boldsymbol{\mu} + \eta_{\lambda,\kappa_R,\kappa_D} \textbf{1}_N+2\kappa_R \boldsymbol{\Lambda}\textbf{w}_-\right), \end{equation}\] 其中 \[\eta_{\lambda,\kappa_R,\kappa_D}=\frac{1- \textbf{1}_N'(\lambda\boldsymbol{\Sigma}+2\kappa_R \boldsymbol{\Lambda}+2\kappa_D\textbf{I}_N)^{-1}(\boldsymbol{\mu}+2\kappa_R\boldsymbol{\Lambda}\textbf{w}_-)}{\textbf{1}'_N(\lambda \boldsymbol{\Sigma}+2\kappa_R \boldsymbol{\Lambda}+2\kappa_D\textbf{I}_N)^{-1}\textbf{1}_N}.\]

该参数用于保证预算约束成立。(12.3) 中的最优权重取决于三个调节参数：\(\lambda\)、\(\kappa_R\) 和 \(\kappa_D\)。
- \(\lambda\) 越大，优化越重视降低风险，而不是追求收益最大化；鉴于风险通常比收益更容易预测，这往往是合理的选择。
- \(\kappa_R\) 越大，(12.2) 对权重调整和交易成本的惩罚越强。在其他参数有限时，若 \(\kappa_R \rightarrow \infty\)，最优权重将趋于当前权重 \(\textbf{w}_-\)。
- \(\kappa_D\) 越大，分散化要求越强。在其他条件不变时，若 \(\kappa_D \rightarrow \infty\)，各资产权重将趋于相等，即 \(1/N\)。
- 当 \(\kappa_R=\kappa_D=0\) 时，模型退化为经典均值—方差配置：最优权重是最大夏普比率组合与最小方差组合的混合，二者分别与 \((\boldsymbol{\Sigma})^{-1} \boldsymbol{\mu}\) 和 \((\boldsymbol{\Sigma})^{-1} \textbf{1}_N\) 成比例。

这个公式看似复杂，实际却相当灵活，也便于求解。要为 \(\lambda\)、\(\kappa_R\) 和 \(\kappa_D\) 选出符合实际的取值，仍需反复测试和调整，相关练习见本章末尾。Pedersen, Babu, and Levine (2020) 提出了类似形式，但把协方差矩阵向样本方差组成的对角矩阵收缩，并让预期收益率在模型信号与锚定组合之间折中。作者指出，这一通用框架与鲁棒优化（另见 W. C. Kim, Kim, and Fabozzi (2014)）、贝叶斯推断（Lai et al. (2011)）、随机矩阵理论下的矩阵去噪以及收缩估计均有联系。事实上，预期收益率的收缩估计由来已久（Jorion (1985)、Kan and Zhou (2007) 和 Bodnar, Parolya, and Schmid (2013)），目的就是分散风险并降低估计误差带来的风险。

12.3 投资组合评估指标

投资组合评估是回测的关键环节。下面的内容并非面面俱到，但会覆盖投资组合评价中最重要的几个方面。

12.3.1 讨论

评估机器学习模型的预测准确性当然很重要，而且不可或缺，参见 10.1 节；但在回测中，投资组合收益最终才是检验策略的标准。任何回测都必须设定一个基准，因为脱离参照物的绝对指标很难说明策略究竟是否有效。

这一原则既适用于投资组合，也适用于机器学习模型。在前几章的大多数实验中，模型在测试集上的 MSE 约为 0.037。与此同时，该测试集月度收益率的方差也是 0.037；而这个方差恰好等于始终预测收益率为 0 时的 MSE。换言之，复杂算法并未真正超越“永远预测为零”这一朴素基准。Gu, Kelly, and Xiu (2020b) 的样本外 \(R^2\) 也采用了这一基准。

在投资组合配置中，最基本的基准是等权组合，即每项资产获得相同权重。它看似简单，却很难被持续超越（参见 DeMiguel, Garlappi, and Uppal (2009) 和 Plyakha, Uppal, and Vilkov (2016)）。理论上，当不确定性、模糊性或估计风险较高时，等权配置可能是最优选择（Pflug, Pichler, and Wozabal (2012)、Maillet, Tokpavi, and Vaucher (2015)、L. Zhao and Gao (2022)）；经验研究也表明，即使在因子层面，它仍难以被击败（Dichtl, Drobetz, and Wendt (2020)）。因此，下文以包含全部股票的等权（EW）组合作为基准。

12.3.2 收益与风险指标

下面定义实务界和学术界常用的收益与风险指标。分别以 \(r^P=(r_t^P)_{1\le t\le T}\) 和 \(r^B=(r_t^B)_{1\le t\le T}\) 表示投资组合与基准的收益率序列；泛指某个收益率序列时，则简写为 \(r_t\)。多数评价方法都利用收益率分布的某些性质。

最简单的指标是平均收益率： \[\bar{r}_P=\mu_P=\mathbb{E}[r^P]\approx \frac{1}{T}\sum_{t=1}^T r_t^P, \quad \bar{r}_B=\mu_B=\mathbb{E}[r^B]\approx \frac{1}{T}\sum_{t=1}^T r_t^B,\]

若 \(\mathbb{E}[r^P]>\mathbb{E}[r^B]\)，投资组合的平均收益高于基准，自然值得进一步关注。上式使用算术平均收益率，也可以改用几何平均收益率： \[\tilde{\mu}_P\approx \left(\prod_{t=1}^T(1+r^P_t) \right)^{1/T}-1 , \quad \tilde{\mu}_B \approx \left(\prod_{t=1}^T(1+r^B_t) \right)^{1/T}-1.\] 几何平均收益率考虑了复利效应，因此会反映波动对长期财富增长的拖累。以两期收益率分别为 \(-r\) 和 \(+r\) 为例，算术平均值为零，而几何平均值 \(\sqrt{1-r^2}-1\) 为负。

命中率与分类任务中的准确率类似，用来衡量仓位方向判断正确的比例：已实现收益率为正时做多，或已实现收益率为负时做空。它可以在资产层面计算，即方向正确的头寸占比24，也可以在投资组合层面计算；还可以基于绝对收益或相对基准的收益来定义。更有意义的一种口径，是策略跑赢基准的期数占比。但命中率本身并不充分，因为许多次小幅盈利，仍可能被少数几次巨额亏损完全抵消。

这里还需澄清一个重要细节。本书此前的监督学习示例都把命中率与 0.5 比较，但这并非合适的基准。若投资者长期看涨并始终押注上涨，其命中率就等于样本中收益率为正的比例。由于资产长期具有正风险溢价，这个比例往往高于 0.5；在本书样本中为 0.556。因此，0.556 才是策略至少应当超越的朴素基准。

收益指标几乎总要与风险指标结合使用。收益率的二阶矩通常用于衡量投资组合的波动幅度：方差越大，收益率和组合价值的起伏越剧烈。因此，收益率的标准差被称为投资组合的波动率。 \[\sigma^2_P=\mathbb{V}[r^P]\approx \frac{1}{T-1}\sum_{t=1}^T (r_t^P-\mu_P)^2, \quad \sigma^2_B=\mathbb{V}[r^B]\approx \frac{1}{T-1}\sum_{t=1}^T (r_t^B-\mu_B)^2.\]

若投资组合与基准的平均收益相同或相近，而 \(\sigma_P^2<\sigma_B^2\)，则前者以更低风险取得了相近收益，因而更具吸引力。

偏度和峰度等高阶矩有时也会用于评价收益分布，但远不如均值和方差常见。C. R. Harvey et al. (2010) 给出了一种在投资组合构建中纳入这些高阶矩的方法。

波动率并不能完整刻画所有风险，因为它同等对待上涨与下跌。实际投资者往往更关心价格下跌时的“坏波动”，而不是上涨时的“好波动”。下行半方差只对负收益率计算离差： \[\sigma^2_-\approx \frac{1}{\text{card}(r_t<0)}\sum_{t=1}^T (r_t-\mu_P)^21_{\{r_t<0\}}.\]

平均收益率和波动率是典型的矩指标。另一些指标则关注收益率分布的尾部与极端事件，风险价值（VaR）就是其中之一。若 \(F_r\) 表示收益率的经验累积分布，则置信水平 \(\alpha\)（通常为 95%）下的 VaR 为 \[\text{VaR}_\alpha(\textbf{r}_t)=F_r(1-\alpha).\]

它对应收益率分布左尾的一个分位点：平均而言，只有 \((1-\alpha)\)% 的结果会比它更差。更保守的指标是条件风险价值（CVaR），也称预期损失（expected shortfall），它计算最差 \(1-\alpha\)% 情景下的平均收益或损失。其经验估计为 \[\text{CVaR}_\alpha(\textbf{r}_t)=\frac{1}{\text{Card}(r_t < \text{VaR}_\alpha(\text{r}_t))}\sum_{r_t < \text{VaR}_\alpha(\text{r}_t)}r_t.\]

再进一步考察极端损失，常用指标是最大回撤，即策略净值从某一历史峰值跌至随后低点时的最大损失。若 \(P_t\) 表示投资组合在时点 \(t\) 的价值，则当前时点的回撤为\[D_T^P=\underset{0 \le t \le T}{\text{max}} P_t-P_T ,\]而区间内的最大回撤为\[MD_T^P=\underset{0 \le s \le T}{\text{max}} \left(\underset{0 \le t \le s}{\text{max}} P_t-P_s, 0\right) .\]

该指标衡量 \([0,T]\) 区间内从历史峰值到随后低点的最大损失，因此是这里所列风险指标中最为保守的一种。

12.3.3 基于因子的评估

按照因子模型的思路，还可以从因子暴露的角度评价策略表现。回顾公式 (3.1)： \[r_{t,n}= \alpha_n+\sum_{k=1}^K\beta_{t,k,n}f_{t,k}+\epsilon_{t,n}, \]

估计得到的 \(\hat{\alpha}_n\) 表示无法由模型中其他因子解释的收益表现。若因变量采用超过无风险利率的超额收益率，且模型只包含市场因子，那么该截距称为 Jensen alpha（Jensen (1968)），通常简称 alpha。另一个估计值 \(\hat{\beta}_{t,M,n}\) 中的 \(M\) 表示市场，因此它衡量资产对市场因子的暴露，即市场贝塔。

随着因子投资兴起，研究者通常还会报告包含更多因子的回归 alpha。加入规模与价值溢价（如 Fama and French (1993)），甚至再加入动量因子（Carhart (1997)），有助于判断策略是否创造了常见因子收益之外的增量价值。

12.3.4 风险调整指标

自 Markowitz (1952) 以来，收益与风险之间的权衡一直是现代金融的基石。把平均收益与波动率合并为一个指标，最简单的做法是计算信息比率： \[IR(P,B)=\frac{\mu_{P-B}}{\sigma_{P-B}},\] 其中 \(P-B\) 表示基于主动收益 \(r_t^P-r_t^B\) 计算均值和标准差。分母 \(\sigma_{P-B}\) 通常称为跟踪误差。

最常见的特例是夏普比率（Sharpe (1966)），此时基准是无风险资产。比较两个投资组合或策略时，人们往往分别比较其夏普比率，而不是直接计算二者之间的信息比率。这类比较还可以配合统计检验，参见 Oliver Ledoit and Wolf (2008)。

也可以把更侧重极端损失的风险指标放在分母。例如，管理账户报告比率（MAR）定义为 \[MAR^P = \frac{\tilde{\mu}_P}{MD^P},\] 而特雷诺比率等于 \[\text{Treynor}=\frac{\mu_P}{\hat{\beta}_M},\] 即用（超额）收益率除以市场贝塔，参见 Treynor (1965)。Hübner (2005) 将其推广到多因子情形，得到广义 Treynor 比率： \[\text{GT}=\mu_P\frac{\sum_{k=1}^K\bar{f}_k}{\sum_{k=1}^K\hat{\beta}_k\bar{f}_k},\] 其中 \(\bar{f}_k\) 是因子 \(f_{t,k}\) 的样本均值。该比率的详细分析性质可参阅原文。

12.3.5 交易成本和换手率

调整投资组合并非没有成本。一般而言，时点 \(t\) 的一次再平衡成本与 \(C_t=\sum_{n=1}^N | \Delta w_{t,n}|c_{t,n}\) 成正比，其中 \(\Delta w_{t,n}\) 是资产 \(n\) 的权重变化，\(c_{t,n}\) 是相应的单位交易成本。后者通常难以准确预测，因此常用市值或买卖价差等变量近似：大市值股票通常流动性更好、成本更低；买卖价差越小，成本也通常越低。

作为一阶近似，计算平均换手率通常很有用： \[\text{Turnover}=\frac{1}{T-1}\sum_{t=2}^T\sum_{n=1}^N|w_{t,n}-w_{t-,n}|,\] 其中 \(w_{t,n}\) 是时点 \(t\) 再平衡后希望持有的目标权重，\(w_{t-,n}\) 是再平衡前、经上一持有期收益漂移后的实际权重。按惯例，初始建仓不计入平均换手率。交易成本可进一步用换手率乘以横截面上的平均或中位单位成本来近似。这只是已实现成本的一阶估计，没有考虑组合规模随时间变化，但粗略估计仍远胜于完全忽略成本。

将交易成本（TC）年化后，可从平均收益率中扣除，以更真实地反映净收益。投资组合 \(P\) 经交易成本调整后的夏普比率为 \[\begin{equation} \tag{12.4} SR_{TC}=\frac{\mu_P-TC}{\sigma_P}. \end{equation}\]

学术研究经常忽略交易成本，但它会显著影响真实交易结果，参见 Novy-Marx and Velikov (2015)。DeMiguel et al. (2020) 说明了如何利用因子投资和风险暴露合并、抵消头寸，从而降低总交易成本。

12.4 常见错误和问题

12.4.1 前视数据

投资组合回测最常见的错误之一，是使用决策时尚不可得的前视数据。例如，稍不注意就会把图 12.2 中危险区间内的样本纳入训练，使时点 \(t\) 使用的标签依赖 \(t+1\)、\(t+2\) 等未来时点的信息。应逐步反复检查代码，确保策略只使用当时已经公布且可以获得的数据，避免产生前视偏差。

12.4.2 回测过拟合

第二个主要问题是回测过拟合，可以把它理解为训练集过拟合在策略研究中的对应现象。该问题早已得到系统研究，例如 White (2000) 和 Romano and Wolf (2005)。在投资组合选择领域，可参阅 Bajgrowicz and Scaillet (2012)、D. H. Bailey and Prado (2014)、Lopez de Prado and Bailey (2020) 及其所引文献。

回测在任一时刻都只有这一份历史数据。第一次结果不理想时，研究者很容易调整参数再试一次；第二次虽有改善却仍不满意时，又可能更换权重方案、采用更复杂的预测模型。如此反复，迟早能在同一份数据上找到“足够好”的策略。问题在于，这个结果可能只是适配了该历史样本，而不是发现了能够延续到未来的规律。

回测过拟合的一个直接后果是，实盘夏普比率通常无法达到回测水平。审慎的从业者往往至少把回测夏普比率打五折（C. R. Harvey and Liu (2015)；Suhonen, Lennkh, and Perez (2017)）。D. H. Bailey and Prado (2014) 进一步提出了对多次策略试验进行校正的夏普比率统计检验，前提是保留所有已测试策略的相关指标。其经多重检验校正的夏普比率统计量为： \[\begin{equation} \tag{12.5} t = \phi\left((SR-SR^*)\sqrt{\frac{T-1}{1-\gamma_3SR+\frac{\gamma_4-1}{4}SR^2}} \right), \end{equation}\] 其中 \(SR\) 是全部已测试策略中最佳策略的夏普比率，而 \[SR^*=\mathbb{E}[SR]+\sqrt{\mathbb{V}[SR]}\left((1-\gamma)\phi^{-1}\left(1-\frac{1}{N}\right)+\gamma \phi^{-1}\left(1-\frac{1}{Ne}\right) \right),\] 表示理论上的平均最大夏普比率。此外，

  • \(T\) 为交易时点数；
  • \(\gamma_3\) 和 \(\gamma_4\) 分别为所选最佳策略收益率的 \(skewness\)（偏度）和 \(kurtosis\)（峰度）；
  • \(\phi\) 为标准正态分布的累积分布函数，\(\gamma\approx 0,577\) 为 Euler-Mascheroni 常数；
  • \(N\) 为尝试过的策略数量。

若上述 \(t\) 低于给定阈值，例如 0.95，那么在考虑全部试验后，观察到的 \(SR\) 就不能视为显著。遗憾的是，实践中往往如此。由公式 (12.5) 可见，实际夏普比率不仅必须高于多次尝试下的理论最大值 \(SR^*\)，样本规模等因素形成的缩放项还必须足够大，使 \(\phi\) 的自变量接近 2，\(t\) 才能超过 0.95。

在科学研究中，反复检验并只报告显著结果的行为通常称为 p 值操纵（p-hacking）。它在金融经济学中并不少见，C. R. Harvey (2017) 详细说明了问题的严重程度。p 值操纵也可能出现在任何广泛使用统计检验的领域，参见 Head et al. (2015)。应对 p 值操纵的常见方法包括：

  1. 不把 p 值作为决策依据（Amrhein, Greenland, and McShane (2019)）；
  2. 使用专门的检测工具（Elliott, Kudrin, and Wuthrich (2019)）；
  3. 采用能够同时处理一组统计量的高级方法，例如对 p 值作贝叶斯校正并纳入 C. R. Harvey (2017) 所讨论的先验判断，或采用 Romano and Wolf (2005)、Simonsohn, Nelson, and Simmons (2014) 提出的其他检验。

第一种选择有其道理，但放弃 p 值以后，决策仍需依赖另一项可能同样主观的标准。

12.4.3 简单保障措施

如本章开头所述，Fabozzi and Prado (2018) 与 R. Arnott, Harvey, and Markowitz (2019) 是两篇强调回测常识的重要文献，其中的建议大多审慎而实用。

还可以对回测结果做一项简单的合理性检查。公式 (12.4) 定义了直观且常用的交易成本调整夏普比率。记基准的该指标为 \(SR_{TC}^B\)；这里把基准定义为可投资范围内全部资产的等权组合，本书数据中约为 1,000 只美国股票。若最佳策略的 \(SR_{TC}^P\) 高于 \(2\times SR_{TC}^B\)，回测流程很可能存在漏洞。

这项经验判断建立在两个前提上：

  1. 样本外检验期足够长；
  2. 策略为只做多组合。

从长期看，现实策略很难以极大幅度持续超越可靠基准。在波动率相近时，若年化收益率能比基准高出 150 个基点，就已经是很出色的结果。若回测显示年化收益率领先基准 5 个百分点以上，反而应先怀疑数据、代码或方法是否存在问题。

12.5 非平稳性的含义：预测很难

本节分为两部分：先讨论金融预测为何如此困难，再介绍一个最初为机器学习提出、但对所有样本外检验都具有启发意义的理论结果。Farmer, Schmidt, and Timmermann (2019) 研究了线性模型的预测拟合度如何随时间变化，发现模型有时表现很好，有时却明显失效。机器学习算法同样没有理由能够免受这种时变性的影响。

12.5.1 一般评论

细心的读者会发现，第 5 至 11 章中机器学习模型的表现并不惊艳。书中有意保留这些不够理想的结果，是为了强调一个关键事实：机器学习不是万能药，也无法凭空把数据变成可靠预测。大多数机器学习预测最终都会失败。这不仅适用于先进而复杂的算法，也适用于较简单的计量经济学方法（Dichtl et al. (2020)），因此研究结果必须接受复现和检验。

原因之一是金融数据噪声极大，从中提取哪怕微弱的信号都很困难；相关讨论可参阅 Timmermann (2018) 的导论。股票因子的表现还会不断随时间变化：某因子今年可能有效，下一年却可能失效或反转。在完全自动化、由数据驱动的资产配置流程中，这类反转可能造成高昂损失。

这正是金融预测与机器学习取得巨大进展的许多领域之间的重要区别。在图像识别中，数字、猫或公共汽车的基本形态相对稳定；在语言处理中，动词仍是动词，语法规则也不会突然改变。这种不变性虽然并非总是容易学习，25 却是计算机视觉和自然语言处理不断进步的重要基础。

因子投资似乎不存在同样稳定的不变性，参见 Cornell (2020)。迄今没有任何单一因子或因子组合，包括非线性组合，能够在数十年间持续解释并准确预测收益率。26 学术文献尚未发现这样的模型；即使一度发现，套利资金也会利用其规律，并使该规律在未来数据中逐渐失效。

12.5.2 没有免费的午餐定理

首先要强调，机器学习中的“没有免费午餐定理”与资产定价中同名的无套利条件并无关系；后者可参阅 Delbaen and Schachermayer (1994) 和较近期的 Cuchiero, Klein, and Teichmann (2016)。机器学习中的原始表述来自 Wolpert (1992a)，也可参阅较新的 Y.-C. Ho and Pepyne (2002)。实际上，“没有免费午餐”包含多个定理，其中两个见 Wolpert and Macready (1997)。

该定理的表述较为抽象，需要先约定符号。假设对任意训练样本 \(S=(\{\textbf{x}_1,y_1\}, \dots, \{\textbf{x}_I,y_I\})\)，都存在一个预言机函数 \(f\)，能够把特征完美映射为标签，即 \(y_i=f(\textbf{x}_i)\)。预言机函数 \(f\) 属于一个很大的函数集合 \(\mathcal{F}\)。另以 \(\mathcal{H}\) 表示预测者用来逼近 \(f\) 的候选函数集合；例如，\(\mathcal{H}\) 可以是前馈神经网络集合、决策树集合，或二者的并集。\(\mathcal{H}\) 中的元素记为 \(h\)，\(\mathbb{P}[h|S]\) 表示给定样本 \(S\) 后 \(h\) 的分布；这一分布通常在很大程度上未知。类似地，\(\mathbb{P}[f|S]\) 表示给定 \(S\) 后预言机函数的分布。最后，特征服从分布 \(\mathbb{P}[\textbf{x}]\)。

现在考虑两个模型 \(h_1\) 和 \(h_2\)。该定理通常针对分类任务表述。给定 \(S\) 后，选择 \(h_k\) 时在训练样本 \(S\) 之外产生的误差可写为： \[\begin{equation} \tag{12.6} E_k(S)= \int_{f,h}\int_{\textbf{x}\notin S} \underbrace{ (1-\delta(f(\textbf{x}),h_k(\textbf{x})))}_{\text{error term}} \underbrace{\mathbb{P}[f|S]\mathbb{P}[h|S]\mathbb{P}[\textbf{x}]}_{\text{distributional terms}}, \end{equation}\] 其中 \(\delta(\cdot,\cdot)\) 是 Kronecker delta 函数： \[\begin{equation} \tag{12.7} \delta(x,y)=\left\{\begin{array}{ll} 0 & \text{if } x\neq y \\ 1 & \text{if } x = y \end{array} .\right. \end{equation}\] 没有免费午餐定理中的一个结论是 \(E_1(S)=E_2(S)\)：仅凭样本 \(S\) 本身，任何算法都不可能在所有问题上平均而言优于其他算法。要构建有效模型，分析师或计量经济学家必须对 \(y\) 与 \(\textbf{x}\) 之间的关系结构提出先验判断，并把这些判断融入模型。代价是，一旦先验判断错误，模型也可能表现不佳。

12.6 第一个示例：完整的回测

下面给出一个较为完整的示例，展示如何在严谨的回测框架中实现机器学习策略。它是 5.2.2 节示例的扩展。与前文相同，整个回测分为四部分：

  1. 创建并初始化变量；
  2. 在主函数中定义策略；
  3. 执行回测循环；
  4. 计算评估指标。

先从变量初始化开始。

sep_oos <- as.Date("2007-01-01")                            # Starting point for backtest
ticks <- data_ml$stock_id %>%                               # List of all asset ids
    as.factor() %>%
    levels()
N <- length(ticks)                                          # Max number of assets
t_oos <- returns$date[returns$date > sep_oos] %>%           # Out-of-sample dates 
    unique() %>%                                            # Remove duplicates
    as.Date(origin = "1970-01-01")                          # Transform in date format
Tt <- length(t_oos)                                         # Nb of dates, avoid T = TRUE
nb_port <- 2                                                # Nb of portfolios/stragegies
portf_weights <- array(0, dim = c(Tt, nb_port, N))          # Initialize portfolio weights
portf_returns <- matrix(0, nrow = Tt, ncol = nb_port)       # Initialize portfolio returns

初始化为回测主体准备了所需对象。示例只比较两种策略：机器学习策略与等权（EW，即 1/N）基准。主权重函数同时封装二者，较复杂的机器学习部分则单独定义。机器学习权重来自 XGBoost 的预测；模型包含 80 棵树，学习率为 0.3，最大树深为 4，复杂度适中。得到预测后，权重规则很简单：只保留预测值高于横截面中位数的一半股票，并在这些股票之间等权配置。

下列函数把学习率 eta、树数 nrounds 等参数直接写在函数体内；也可以把它们改成与数据输入并列的函数参数。一个关键区别是，本例以未来 12 个月收益率作为标签，原因见 4.6 节。为加快计算，还按照 Coqueret and Guida (2020) 的建议，只保留标签分布顶部和底部各 20% 的样本；这两个筛选阈值同样可以参数化。

weights_xgb <- function(train_data, test_data, features){ 
    train_features <- train_data %>% dplyr::select(features) %>% as.matrix()  # Indep. variable
    train_label <- train_data$R12M_Usd / exp(train_data$Vol1Y_Usd)            # Dep. variable
    ind <- which(train_label < quantile(train_label,0.2)|                     # Filter
                   train_label > quantile(train_label, 0.8))
    train_features <- train_features[ind, ]                                   # Filt'd features
    train_label <- train_label[ind]                                           # Filtered label
    train_matrix <- xgb.DMatrix(data = train_features, label = train_label)   # XGB format
    fit <- train_matrix %>% 
        xgb.train(data = .,                       # Data source (pipe input)
                  eta = 0.3,                      # Learning rate
                  objective = "reg:squarederror", # Number of random trees
                  max_depth = 4,                  # Maximum depth of trees
                  nrounds = 80,                   # Number of trees used
                  verbose = 0                     # No comments
        )
    xgb_test <- test_data %>%                     # Test sample => XGB format
        dplyr::select(features) %>% 
        as.matrix() %>%
        xgb.DMatrix()
    
    pred <- predict(fit, xgb_test)                # Single prediction
    w <- pred > median(pred)                      # Keep only the 50% best predictions
    w$weights <- w / sum(w)
    w$names <- unique(test_data$stock_id)
    return(w)                                     # Best predictions, equally-weighted
}

与 6.4.6 节的设定相比，这里的标签不仅使用长期收益，还加入了波动率调整。分母是波动率分位数的指数，因此该标签可视为受夏普比率启发的风险调整收益；模型预测的不是原始收益率，而是风险调整后的收益。对波动率很低的股票，标签中的收益率基本不变；对波动率很高的股票，收益率会被除以接近 3 的系数，因为 exp(1)=2.718。

随后，把这个函数纳入总的权重生成函数，由后者统一处理 EW 基准与机器学习策略。

    }
    if(j == 2){                                 # This is the ML strategy.
        return(weights_xgb(train_data, test_data, features))
    }
}

权重函数准备完毕后，即可进入主回测循环。由于每个再平衡时点都要重新训练较大模型，整个循环计算量很高，在性能较弱且只使用 CPU 的机器上可能耗时数小时。函数式编程可以提高执行效率，相关练习见本章末尾。作为对照，简单的等权基准完全可以只用 tidyverse 函数实现。

m_offset <- 12                                          # Offset in months for buffer period
train_size <- 5                                         # Size of training set in years
for(t in 1:(length(t_oos)-1)){                          # Stop before last date: no fwd ret.!
    if(t%%12==0){print(t_oos[t])}                       # Just checking the date status
    train_data <- data_ml %>% filter(date < t_oos[t] - m_offset * 30,   # Roll window w. buffer
                                    date > t_oos[t] - m_offset * 30 - 365 * train_size)    
    test_data <- data_ml %>% filter(date == t_oos[t])   # Test sample  
    realized_returns <- test_data %>%                   # Computing returns via:
        dplyr::select(R1M_Usd)                          # 1M holding period!
    for(j in 1:nb_port){    
        temp_weights <- portf_compo(train_data, test_data, features, j) # Weights
        ind <- match(temp_weights$names, ticks) %>% na.omit()           # Index: test vs all
        portf_weights[t,j,ind] <- temp_weights$weights                  # Allocate weights 
        portf_returns[t,j] <- sum(temp_weights$weights * realized_returns) # Compute returns
    } 
}

其次，需要正确计算换手率，也就是再平衡带来的权重变化。该函数同时接收目标权重和全部资产收益率，因为再平衡前的实际权重并不等于上期目标权重：持有期间各资产收益不同，会使权重发生漂移。只有先根据已实现收益更新上期权重，再与本期目标权重比较，才能得到真实换手率。

turnover <- function(weights, asset_returns, t_oos){ 
    turn <- 0
    for(t in 2:length(t_oos)){
        realised_returns <- returns %>% filter(date == t_oos[t]) %>% dplyr::select(-date)
        prior_weights <- weights[t-1,] * (1 + realised_returns) # Before rebalancing
        turn <- turn + apply(abs(weights[t,] - prior_weights/sum(prior_weights)),1,sum)
    }
    return(turn/(length(t_oos)-1))
}

定义换手率后，再把它纳入评估函数，与平均收益率、波动率、夏普比率和 VaR 一并计算。

perf_met <- function(portf_returns, weights, asset_returns, t_oos){ 
    avg_ret <- mean(portf_returns, na.rm = T)                     # Arithmetic mean 
    vol <- sd(portf_returns, na.rm = T)                           # Volatility
    Sharpe_ratio <- avg_ret / vol                                 # Sharpe ratio
    VaR_5 <- quantile(portf_returns, 0.05)                        # Value-at-risk
    turn <- 0                                                     # Initialisation of turnover
    for(t in 2:dim(weights)[1]){
        realized_returns <- asset_returns %>% filter(date == t_oos[t]) %>% dplyr::select(-date)
        prior_weights <- weights[t-1,] * (1 + realized_returns)
        turn <- turn + apply(abs(weights[t,] - prior_weights/sum(prior_weights)),1,sum)
    }
    turn <- turn/(length(t_oos)-1)                                # Average over time
    met <- data.frame(avg_ret, vol, Sharpe_ratio, VaR_5, turn)    # Aggregation of all of this
    rownames(met) <- "metrics"
    return(met)
}

接着构建一个汇总函数，依次计算每种策略的评估指标。

perf_met_multi <- function(portf_returns, weights, asset_returns, t_oos, strat_name){
    J <- dim(weights)[2]              # Number of strategies 
    met <- c()                        # Initialization of metrics
    for(j in 1:J){                    # One very ugly loop
        temp_met <- perf_met(portf_returns[, j], weights[, j, ], asset_returns, t_oos)
        met <- rbind(met, temp_met)
    }
    row.names(met) <- strat_name      # Stores the name of the strat
    return(met)
}

12.7 第二个示例：回测过拟合

本章最后用数值示例说明 12.4.2 节的回测过拟合。先构建一个函数，用于批量计算多种简单策略的评估指标。每种策略都是单纯的因子押注，由三个输入决定：所选特征，例如市值；阈值，即该特征的分位点；以及方向，即做多特征分布的上端还是下端。

strat <- function(data, feature, thresh, direction){
    data_tmp <- dplyr::select(data, feature, date, R1M_Usd)       # Data
    colnames(data_tmp)[1] <- "feature"                            # Colname
    data_tmp %>% 
        mutate(decision = direction * feature > direction * thresh) %>% # Investment decision
        group_by(date) %>%                                          # Date-by-date  analysis    
        mutate(nb = sum(decision),                                  # Nb assets in portfolio
               w = decision / nb,                                   # Weights of assets
               return = w * R1M_Usd) %>%                            # Asset contribution
        summarise(p_return = sum(return)) %>%                       # Portfolio return
        summarise(avg = mean(p_return), sd = sd(p_return), SR = avg/sd) %>% # Perf. metrics
        return()
}

先用一组参数检验函数：选择市净率（Pb），方向为正，阈值为 0.3。这表示策略买入 Pb 高于横截面第 30 百分位的股票。

最后计算公式 (12.5) 的多重检验校正统计量：

DSR <- function(SR, Tt, M, g3, g4, SR_m, SR_v){ # First, we build the function
    gamma <- -digamma(1)                        # Euler-Mascheroni constant
    SR_star <- SR_m + sqrt(SR_v)*((1-gamma)*qnorm(1-1/M) + gamma*qnorm(1-1/M/exp(1))) # SR*
    num <- (SR-SR_star) * sqrt(Tt-1)            # Numerator
    den <- sqrt(1 - g3*SR + (g4-1)/4*SR^2)      # Denominator
    return(pnorm(num/den))
}

最后代入所需参数。图 12.4 左上角基于市值的策略，在这批试验中取得了最高夏普比率。
