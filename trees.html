6 树模型

分类树和回归树是结构简单却功能强大的递归划分算法，因 Breiman et al. (1984) 的专著而得到普及。处理表格数据时，决策树及其扩展通常是十分有效的预测工具。机器学习竞赛，尤其是 Kaggle 竞赛14，有相当多的获奖方案采用树模型的改进算法。例如，Olson et al. (2018) 对生物信息学算法的荟萃研究发现，在不含神经网络的 13 种算法中，提升树与随机森林排名前两位。

近年来，机器学习在金融领域迅速普及，许多研究开始把树模型用于投资组合配置。相关文献包括但不限于 Ballings et al. (2015)、Patel et al. (2015a)、Patel et al. (2015b)、Moritz and Zimmermann (2016)、Krauss, Do, and Huck (2017)、Gu, Kelly, and Xiu (2020b)、Guida and Coqueret (2018a)、Coqueret and Guida (2020) 和 Simonian et al. (2019)。其中一项代表性工作是 Bryzgalova, Pelger, and Zhu (2019)：作者利用简单树对股票排序并据此构造因子，将其称为资产定价树。另一项近期研究 X. He et al. (2021) 则试图为资产定价设计全局分裂准则。

本章回顾树模型的主要方法，并讨论它们在投资组合选择中的应用。

6.1 简单树

6.1.1 原理

决策树的目标是把数据集递归地划分为内部相对同质的组。给定目标变量 \(\mathbf{Y}\) 和特征 \(\mathbf{X}\)，树反复将样本分成若干子组，通常每次一分为二，使各组内部的 \(\mathbf{Y}\) 尽可能相似。每次分裂都依据特征集中的某一个变量。术语上，若 \(\mathbf{Y}\) 为实数变量，称为回归树；若 \(\mathbf{Y}\) 为类别变量，则称为分类树。

在给出正式定义前，先用图 6.1 说明这一过程。图中有 12 颗星，每颗星有三个特征：颜色、大小和复杂度（分支数）。

图 6.1：基本树结构；分裂过程的可视化。

目标变量是颜色；为便于理解，可把它看作与颜色对应的波长。第一次分裂可以依据大小或复杂度。复杂度显然更合适：复杂的星为蓝色或绿色，简单的星为黄色、橙色或红色。若按大小分裂，小星组会同时包含蓝色和黄色，大星组则会同时包含绿色和橙色，组内颜色并不一致。

第二步把两个子组各自再分裂一层。此时只有大小这一特征可用，分裂方式很直接。最终，这棵示意树得到四个内部一致的叶节点。对应到因子投资，颜色可代表业绩：红色表示高收益，蓝色表示表现平平；星的大小与复杂度则替换为市值、会计比率等公司特征。树模型要寻找的，正是能够把未来表现较好与较差的公司区分开的特征。

下面正式说明回归树的构建，也就是分裂过程，主要依据 Breiman et al. (1984) 以及 Hastie, Tibshirani, and Friedman (2009) 第 9 章。每条样本由标签 \(y_i\) 与特征向量 \(\mathbf{x}_i\) 组成；给定大小为 \(I\) 的样本，回归树寻找一个分裂点，使两个子节点内 \(y_i\) 的总变异最小，两个子节点的样本数不必相同。算法分两步进行：先针对每个特征 \(x_i^{(k)}\) 找到使 \(\mathbf{Y}\) 最同质的最佳分裂点，再从所有特征中选出同质性最高的一个。

回归树中的同质性与方差密切相关。我们希望每个子节点内的 \(y_i\) 尽可能相近，因此要分别计算两个节点内部的变异或离散程度，再把二者相加。不能直接相加方差，因为那样没有考虑两个节点的相对大小；因此采用总离差，也就是方差乘以节点中的样本数。

下面的记号稍显繁复，因为上标 \(k\) 用来标识特征；理解思路时可以暂时忽略上标。第一步是为每个特征寻找最佳分裂点，即求解 \(\underset{c^{(k)}}{\text{argmin}} \ V^{(k)}_I(c^{(k)})\)，其中 \[\begin{equation} \tag{6.1} V^{(k)}_I(c^{(k}))= \underbrace{\sum_{x_i^{(k)}<c^{(k)}}\left(y_i-m_I^{k,-}(c^{(k)}) \right)^2}_{\text{Total dispersion of first cluster}} + \underbrace{\sum_{x_i^{(k)}>c^{(k)}}\left(y_i-m_I^{k,+}(c^{(k)}) \right)^2}_{\text{Total dispersion of second cluster}}, \end{equation}\] 且 \[\begin{align*} m_I^{k,-}(c^{(k)})&=\frac{1}{\#\{i,x_i^{(k)}<c^{(k)} \}}\sum_{\{x_i^{(k)}<c^{(k)} \}}y_i \quad \text{ and } \\ m_I^{k,+}(c^{(k)})&=\frac{1}{\#\{i,x_i^{(k)}>c^{(k)} \}}\sum_{\{x_i^{(k)}>c^{(k)} \}}y_i \end{align*}\] 这两项分别是 \(Y\) 在特征 \(X^{(k)}\) 小于或大于阈值 \(c\) 时的均值。基数函数 \(\#\{\cdot\}\) 计算集合中的样本数。因此，对特征 \(k\) 而言，最优分裂点 \(c^{k,*}\) 就是使两个子组总离差最小的点。

各特征的最优分裂点满足 \(c^{k,*}= \underset{c^{(k)}}{\text{argmin}} \ V^{(k)}_I(c^{(k)})\)。在所有候选特征中，树最终选择使总离差最小的特征：\(k^*=\underset{k}{\text{argmin}} \ V^{(k)}_I(c^{k,*})\)。

完成一次分裂后，算法在新得到的两个子节点上继续递归。分裂何时停止可由多种准则决定（见第 6.1.3 节）。最简单的做法是限制树的最大层数，即深度；另一种常见做法是要求每次分裂至少带来某个幅度的增益。如果分裂带来的离差下降低于阈值，就不再执行。关于决策树的进一步技术讨论，可参见 Hastie, Tibshirani, and Friedman (2009) 第 9.2.4 节。

树训练完成后，对新样本作预测十分直接：根据该样本的特征值沿树向下移动，最终落入某个叶节点；该叶节点内标签的平均值就是预测结果。当然，这只适用于数值型标签，分类标签的处理将在下文说明。

6.1.2 分类树的进一步说明

分类任务比回归任务略复杂，最明显的差异在于如何度量离散程度或异质性。损失函数必须考虑到最终输出不是一个标量，而是一个向量。输出 \(\tilde{\textbf{y}}_i\) 的元素个数等于标签类别数，每个元素表示样本属于相应类别的概率。

例如，若标签有“买入”“持有”“卖出”三个类别，每个样本的标签就包含三列。按这一顺序，(1, 0, 0) 表示“买入”。相关概念见第 4.5.2 节。

在树中，每个节点会汇总其中样本的类别标签。典型输出可能是 (0.6, 0.1, 0.3)，分别表示该节点内 60% 的样本属于“买入”、10% 属于“持有”、30% 属于“卖出”。

损失函数必须处理标签的这种多维性。树模型追求节点内部同质，因此会惩罚没有集中到某一类别的分布。例如，(0.3, 0.4, 0.3) 比 (0.8, 0.1, 0.1) 更难作出明确分类。

因此，分类树追求节点的“纯度”：寻找能够产生尽可能纯的子节点的分裂准则，使一个类别占据明显优势，或至少只有少数类别占优。文献提出了多种度量，它们都基于节点内的类别比例。若共有 \(J\) 个类别，并以 \(p_j\) 表示各类别比例，则每个叶节点常用的损失函数包括：

  • 基尼杂质指数： \(1-\sum_{j=1}^Jp_j^2;\)
  • 误分类率：\(1-\underset{j}{\text{max}}\, p_j;\)
  • 熵： \(-\sum_{j=1}^J\log(p_j)p_j.\)

基尼不纯度等于 1 减去衡量投资组合集中程度的赫芬达尔指数；换言之，树在寻找类别分布最集中的划分。当某个 \(p_j=1\)、其余均为零时，基尼不纯度取得最小值 0；其最大值为 \(1-1/J\)，在所有 \(p_j=1/J\) 时取得。另外两种损失也有类似性质。误分类率不可导，这是实践中更常选用基尼不纯度或熵的原因之一。

树生长完成后，新样本会落入某个最终叶节点。该叶节点记录各类别在其中所占的比例；作预测时，通常选择比例或概率最高的类别。

6.1.3 剪枝准则

构建树时，可以不断分裂，直至得到完全生长的树，也就是：

  • 每个样本各自落入一个叶节点；和/或
  • 每个叶节点中的样本都无法再依据现有特征进一步分开。

到这一步，树已无法继续分裂。

当预测变量具有解释力、数量多且为数值型时，完全生长的树通常能近乎完美地拟合训练数据。但训练样本中特别细微的模式对样本外预测未必有用。例如，模型即使完美捕捉了 2000 至 2006 年的规律，也未必能用于 2007 至 2009 年。树中最靠近根节点的部分通常最可靠，因为它们覆盖大量数据；这些上层节点的均值由众多观测计算而得。前几次分裂决定最一般的规律，越深的分裂则越可能只是在刻画训练样本的特殊之处。

因此，必须限制树的规模以避免过拟合。剪枝可以依据多种准则，常见做法包括：

  • 规定每个终端节点（叶节点）的最小样本数。这样可保证每个叶节点包含足够多的观测，使标签均值的估计更可靠。
  • 规定允许节点继续分裂所需的最小样本数。这一准则与上一项密切相关。
  • 规定拟合改善的最低阈值。若分裂不能充分降低损失，就没有必要执行。用户给定一个较小的 \(\epsilon>0\)，只有当分裂后的损失小于分裂前损失的 \(1-\epsilon\) 倍时，才接受该分裂。
  • 限制树的深度。深度是从根节点到任一叶节点所经历的最大分裂次数。

下面的示例同时采用以上所有准则，但实际应用中通常选用其中一两个就足够。

6.1.4 代码与解释

先拟合一棵简单树并解释其结果。这里使用 rpart 软件包及其绘图工具 rpart.plot。标签是未来 1 个月收益率，特征为样本中所有可用的预测变量，模型在完整样本上训练。

## Loading required package: rpart
library(rpart)              # Tree package  
library(rpart.plot)         # Tree plot package
formula <- paste("R1M_Usd ~", paste(features, collapse = " + ")) # Defines the model 
formula <- as.formula(formula)                                   # Forcing formula object
fit_tree <- rpart(formula,
             data = data_ml,     # Data source: full sample
             minbucket = 3500,   # Min nb of obs required in each terminal node (leaf)
             minsplit = 8000,    # Min nb of obs required to continue splitting
             cp = 0.0001,        # Precision: smaller = more leaves
             maxdepth = 3        # Maximum depth (i.e. tree levels)
             ) 
rpart.plot(fit_tree)             # Plot the tree

图 6.2：基于公司特征的简单树。因变量为未来 1 个月收益率。

树形图通常遵循一项约定：每个节点用布尔表达式给出分裂条件。若条件为真，样本进入左侧子节点；若条件不成立，则沿右侧分支继续。图 6.2 中，根节点首先按照市净率分裂。若样本的 Pb 得分（或取值）高于 0.025，就进入左侧；否则进入右侧子节点。

每个节点显示两项重要指标：节点内标签的平均值，以及该节点所占的样本比例。根节点包含全部样本（100%），未来 1 个月平均收益率为 1.3%。下一层的左节点包含约 98% 的观测，平均收益率为 1.2%；右节点只包含 2%，平均收益率却高达 5.9%。后者可能只是本样本特有的现象。

算法以同样方式继续分裂各节点，直到满足停止条件；本例通常是达到最大深度。节点颜色表示平均收益率，从白色的低收益逐渐过渡到蓝色的高收益。最左侧叶节点的平均收益率最低，其中公司同时满足以下全部条件：

  • Pb 分数高于 0.025；
  • 3 个月市值得分高于 0.16；
  • 过去 3 个月的日均交易量得分高于 0.85。

树模型的一个特点是各节点的样本量可能非常不均衡：少数节点汇集了几乎全部观测，另一些很小的节点则只包含少量异常值。这种性质并不理想，因为小节点更可能反映偶然现象，难以推广到样本外。

因此，构建树时需要施加限制。代码中的 minbucket = 3500 要求每个叶节点至少包含 3500 个样本；minsplit 则要求一个节点至少有 8000 个观测，才允许继续分裂。这些阈值应随训练样本规模调整。参数 cp = 0.0001 要求分裂后的损失低于分裂前的 0.9999 倍。最后，最大深度为 3，意味着从根节点到任一叶节点最多经过三次分裂。

若以叶节点数衡量树的复杂度，那么复杂度随 minbucket、minsplit 和 cp 增大而降低，随最大深度增大而提高。

模型训练完成后，任一样本的预测值就是该样本所在叶节点内标签的平均值。

predict(fit_tree, data_ml[1:6,]) # Test (prediction) on the first six instances of the sample
##          1          2          3          4          5          6 
## 0.01088066 0.01088066 0.01088066 0.01088066 0.01088066 0.01088066

结合图形可知，前六个样本都落在从左侧数第二个叶节点中。

为检验树的前几次分裂是否合理，下面分别绘制未来收益率相对于市值、市净率和交易量的平滑条件均值。

图中表明，按市值和市净率分裂具有一定依据：这两个特征得分较低时，平均月收益率较高，曲线左端接近 +4%。相比之下，交易量与未来收益率的关系没有这么明显。

最后，在测试集上评估单棵树的预测表现；该树只用训练集拟合。这里使用一棵更深的树，最大深度为 5。

fit_tree2 <- rpart(formula, 
             data = training_sample,     # Data source: training sample

## [1] 0.03700039
mean(predict(fit_tree2, testing_sample) * testing_sample$R1M_Usd > 0) # Hit ratio
## [1] 0.5416619

均方误差通常难以直观解释，因为预测收益率的误差不容易直接换算为投资决策的损益。命中率更直观，它衡量正确判断收益率方向的比例。不过，该指标也不完美：55% 的小额盈利完全可能被 45% 的大额亏损抵消。尽管如此，命中率仍被广泛使用，也对应二元分类中的准确率。本例的命中率为 0.542，表现尚可。虽然超过 50% 看似有价值，但交易成本会侵蚀收益，因此实际基准可能至少要达到 52%。

6.2 随机森林

树能直观呈现 \(\mathbf{Y}\) 与 \(\mathbf{X}\) 的关系，还可以通过组合多个预测模型来进一步改进。这种模型聚合方法将在第 11 章得到更系统、详细的讨论。

6.2.1 原理

面对多种候选模型时，通常无法事先确定哪一个最好。若各模型的误差相关性不高，将它们组合起来便能分散预测误差。Schapire (1990) 奠定了模型多样化的部分理论基础。

T. K. Ho (1995) 随后讨论了更实际的问题，而 Breiman (2001) 是随机森林的主要参考文献。Yin (2020) 成功地用 Bagging 聚合股票收益预测。要从简单树构造多个预测模型，主要有两种方法；随机森林将二者结合起来：

  • 第一，在相似但不完全相同的数据集上训练各棵树。具体可通过 Bootstrap 重采样实现：对每棵树分别以有放回或无放回方式抽取样本，从而在每次建树时得到新的训练数据。
  • 第二，减少每棵树可使用的预测变量。用户先指定保留多少个特征，算法再为每棵树随机抽取相应数量的特征，使不同树基于不同的特征子集。

这样便能生成许多彼此不同的树，再把它们加权组合成一个集成模型。通常使用等权重，这是一种不预设哪棵树更优的稳健选择。图 6.4 展示了这种简单组合，也就是 Bagging；最终预测为各棵树预测值的平均数。

图 6.4：通过随机森林组合树输出。

随机森林借助重采样与特征随机化，通常比单棵树更有效。Ballings et al. (2015)、Patel et al. (2015a)、Krauss, Do, and Huck (2017) 和 Huck (2019) 都报告了良好表现。Breiman (2001) 最初针对分类树推导了随机森林的理论性质。在分类任务中，各棵树分别投票，得票最多的类别成为最终预测；若票数相同，可以随机打破平局。Breiman (2001) 将间隔函数定义为 \[mg=M^{-1}\sum_{m=1}^M1_{\{h_m(\textbf{x})=y\}}-\max_{j\neq y}\left(M^{-1}\sum_{m=1}^M1_{\{h_m(\textbf{x})=j\}}\right),\] 左侧第一项针对 \(M\) 棵树计算；以 \(h_m\) 表示第 m 棵树时，它等于 \(h_m\) 根据 \(\textbf{x}\) 投给真实类别 \(y\) 的平均票数；第二项是任一错误类别所获平均票数的最大值。间隔越大，集成森林正确分类的信心越强。泛化误差就是 \(mg\) 严格小于零的概率。Breiman (2001) 证明，集成模型的泛化误差上界为 \(\bar{\rho}(1-s^2)/s^2\)，其中
- \(s\) 是各分类器的强度，即平均质量15；
- \(\bar{\rho}\) 是学习器之间的平均相关系数。

Breiman (2001) 还证明，当树的数量趋于无穷时，泛化误差收敛到一个有限值。这解释了为什么单纯增加随机森林中的树数通常不会导致过拟合。

Breiman (2001) 的原始论文主要研究分类模型，后续文献则进一步分析了回归森林，参见 Biau (2012) 和 Scornet et al. (2015)。分类集成的更多结果可见 Biau, Devroye, and Lugosi (2008)；Denil, Matheson, and De Freitas (2014) 的短篇综述总结了该领域的近期进展。

6.3 提升树：AdaBoost

与等权聚合相比，提升方法更进一步。随机森林依靠多棵相互不同的树来改善整体预测；提升方法则在每加入一棵新树时，都有针对性地迭代改进模型。提升学习有多种实现，本章介绍两种适合树模型的方法。第一种是 AdaBoost（adaptive boosting，自适应提升），它逐步提高高误差样本的重要性；第二种是 XGBoost，每棵新树都以降低训练样本的当前损失为目标。

6.3.1 方法

AdaBoost 源于 Freund and Schapire (1997) 和 Freund and Schapire (1996)，系统介绍可参见 Schapire and Freund (2012) 的专著。J. Friedman et al. (2000) 提出了 Real AdaBoost 等扩展，Drucker (1997) 将方法推广到回归问题，Breiman et al. (2004) 则给出了理论分析。

算法的一般框架如下：

  • 把所有样本权重初始化为 \(w_i=I^{-1}\)；
  • 对 \(m=1,\dots,M\) 依次执行：
  1. 寻找学习器 \(l_m\)，使加权损失 \(\sum_{i=1}^Iw_iL(l_m(\textbf{x}_i),\textbf{y}_i)\) 最小；
  2. 计算学习者权重 \[\begin{equation} \tag{6.2} a_m=f_a(\textbf{w},l_m(\textbf{x}),\textbf{y}); \end{equation}\]
  3. 更新样本权重 \[\begin{equation} \tag{6.3} w_i \leftarrow w_ie^{f_w(l_m(\textbf{x}_i), \textbf{y}_i)}; \end{equation}\]
  4. 重新标准化 \(w_i\)，使其总和为 1。
  • 样本 \(\textbf{x}_i\) 的最终输出是 \(\sum_{m=1}^M a_ml_m(\textbf{x}_i)\) 的函数： \[\begin{equation} \tag{6.4} \tilde{y}_i=f_y\left(\sum_{m=1}^M a_ml_m(\textbf{x}_i) \right). \end{equation}\]

这一框架适用于 AdaBoost 的多种变体，下面将具体说明函数 \(f_a\) 和 \(f_w\)。

  1. 第一步寻找使加权损失最小的学习器（树）\(l_m\)。基础损失函数 \(L\) 取决于具体任务是回归还是分类。
  2. 第二、三步是 AdaBoost 的核心，规定了算法如何按顺序自适应。既然目标是聚合多个模型，就不必让所有学习器等权，而可以由 \(f_a\) 为每个学习器确定权重。误差越小、预测越准确的学习器，理应获得越大的权重。
  3. 第三步调整观测的样本权重。函数 \(f_w\) 会提高当前模型预测不佳、误差较大样本的权重，使下一个学习器更加关注这些难以预测的样本。
  4. 第四步只是把样本权重重新缩放为和等于 1。

表 6.1 给出文献中两组具体的加权函数。原始 AdaBoost（Freund and Schapire (1996)；Freund and Schapire (1997)）处理标签仅取 +1 和 -1 的二元分类；第二组来自 Drucker (1997)，用于实值标签的回归任务。其他形式可参见 Schapire (2003) 和 Ridgeway, Madigan, and Richardson (1999)。

表 6.1： AdaBoost 类算法的函数示例。
二元分类（原始 AdaBoost） 回归（Drucker，1997）
单个样本误差 \(\epsilon_i=\textbf{1}_{\left\{y_i\neq l_m(\textbf{x}_i) \right\}}\) \(\epsilon_i=\frac{|y_i- l_m(\textbf{x}_i)|}{\underset{i}{\max}|y_i- l_m(\textbf{x}_i)|}\)
由 \(f_a\) 确定学习器权重 \(f_a=\log\left(\frac{1-\epsilon}{\epsilon} \right)\)，其中 \(\epsilon=I^{-1}\sum_{i=1}^Iw_i \epsilon_i\) \(f_a=\log\left(\frac{1-\epsilon}{\epsilon} \right)\)，其中 \(\epsilon=I^{-1}\sum_{i=1}^Iw_i \epsilon_i\)
由 \(f_w(i)\) 确定样本权重 \(f_w=f_a\epsilon_i\) \(f_w=f_a\epsilon_i\)
由 \(f_y\) 确定输出函数 \(f_y(x) = \text{sign}(x)\) 预测的加权中位数

下面解释原始 AdaBoost 的设定。误差项 \(\epsilon_i=\textbf{1}_{\left\{y_i\neq l_m(\textbf{x}_i) \right\}}\) 是一个指示变量，用于记录预测是否错误；标签本身只能取 +1 或 -1。总体误差 \(\epsilon\in [0,1]\) 是单个样本误差的加权平均。对于第 \(m^{th}\) 个学习器，方程 (6.2) 给出的权重为 \(a_m=\log\left(\frac{1-\epsilon}{\epsilon} \right)\)。函数 \(x\mapsto \log((1-x)x^{-1})\) 在 \([0,1]\) 上单调递减，并在 \(x=1/2\) 处由正变负。因此，平均误差越小，学习器获得的正权重越大；若误差过大，权重甚至会变为负数。特别地，\(\epsilon>1/2\) 表示学习器超过一半时间都预测错误，此时通常应将其舍弃。

样本权重的更新遵循相似逻辑。新的样本权重正比于 \(w_i\left(\frac{1-\epsilon}{\epsilon} \right)^{\epsilon_i}\)。若预测正确、\(\epsilon_i=0\)，权重不变；若预测错误、\(\epsilon_i=1\)，则按照总体误差 \(\epsilon\) 调整。当学习器表现较好，即 \(\epsilon<1/2\) 时，\((1-\epsilon)/\epsilon>1\)，被错分样本的权重会上升，下一轮学习器因而会更加关注样本 \(i\)。

最终预测取各学习器预测加权和的符号：加权和为正时预测 +1，否则预测 -1。17 加权和恰好为零的概率可以忽略。数值型标签的处理稍复杂，详见 Drucker (1997) 第 3 节步骤 8。

最后说明样本加权的两种实现方式。第一种直接修改损失函数。对于回归树，方程 (6.1) 可自然推广为 \[V^{(k)}_N(c^{(k)}, \textbf{w})= \sum_{x_i^{(k)}<c^{(k)}}w_i\left(y_i-m_N^{k,-}(c^{(k)}) \right)^2 + \sum_{x_i^{(k)}>c^{(k)}}w_i\left(y_i-m_N^{k,+}(c^{(k)}) \right)^2,\]

因此，样本权重 \(w_i\) 越大，该样本对所在节点总离差的贡献越大。分类任务中的修改更复杂，样本加权树的生长算法示例可见 Ting (2002)。这一思路与通过损失矩阵调整误分类风险密切相关（参见 Hastie, Tibshirani, and Friedman (2009) 第 9.2.4 节）。

第二种方式是按样本权重随机抽样。若样本权重为 \(w_i\)，便可按照由 \(w_i\) 确定的分布抽取训练样本；权重越大的样本，进入训练集的概率越高。原始 AdaBoost 算法采用的正是这种方法。

6.4 提升树：极端梯度提升

树提升（tree boosting）的思想由 Mason et al. (2000)、J. H. Friedman (2001) 和 J. H. Friedman (2002) 等人的工作推广开来。与随机森林对学习器进行相对独立的组合不同，提升法会在学习器层面逐步调整并优化模型。在每一步 \(s\)，模型之和为 \(M_S=\sum_{s=1}^{S-1}m_s+m_S\)；新增学习器 \(m_S\) 的构造目标，正是降低集成模型 \(M_S\) 在训练样本上的损失。

下面主要沿用 T. Chen and Guestrin (2016) 的原始论述，因为其算法不仅预测精度出色，而且具有很高的可定制性；本书的实证部分也采用他们的实现。另一种广受欢迎的选择是 LightGBM（参见 G. Ke et al. (2017)）。XGBoost 要最小化的目标函数为 \[O=\underbrace{\sum_{i=1}^I \text{loss}(y_i,\tilde{y}_i)}_{\text{error term}} \quad + \underbrace{\sum_{j=1}^J\Omega(T_j)}_{\text{regularization term}}.\] 第一项对所有样本求和，衡量真实标签与模型输出之间的差异；第二项对所有树求和，用于惩罚过于复杂的模型。

为便于说明，我们用最简单的平方损失 \(\text{loss}(y,\tilde{y})=(y-\tilde{y})^2\) 完整推导，此时： \[O=\sum_{i=1}^I \left(y_i-m_{J-1}(\mathbf{x}_i)-T_J(\mathbf{x}_i)\right)^2+ \sum_{j=1}^J\Omega(T_j).\]

6.4.1 损失项

假设已经构建了所有树 \(T_{j}\)，其索引为 \(j=1,\dots,J-1\)，从而得到模型 \(M_{J-1}\)。接下来的问题是：怎样以最优方式选择新树 \(T_J\)？将目标函数改写为 \[\begin{align*} O&=\sum_{i=1}^I \left(y_i-m_{J-1}(\mathbf{x}_i)-T_J(\mathbf{x}_i)\right)^2+ \sum_{j=1}^J\Omega(T_j) \\ &=\sum_{i=1}^I\left\{y_i^2+m_{J-1}(\mathbf{x}_i)^2+T_J(\mathbf{x}_i)^2 \right\} + \sum_{j=1}^{J-1}\Omega(T_j)+\Omega(T_J) \quad \text{(squared terms + penalization)}\\ & \quad -2 \sum_{i=1}^I\left\{y_im_{J-1}(\mathbf{x}_i)+y_iT_J(\mathbf{x}_i)-m_{J-1}(\mathbf{x}_i) T_J(\mathbf{x}_i))\right\}\quad \text{(cross terms)} \\ &= \sum_{i=1}^I\left\{-2 y_iT_J(\mathbf{x}_i)+2m_{J-1}(\mathbf{x}_i) T_J(\mathbf{x}_i))+T_J(\mathbf{x}_i)^2 \right\} +\Omega(T_J) + c \end{align*}\] 在第 \(J\) 步，所有已知项（即只涉及截至 \(J-1\) 步结果的项）都不影响当前优化，因此被并入常数 \(c\)。

采用二次损失时，推导比较直接。对于更复杂的损失函数，则使用泰勒展开，详见原始论文。

6.4.2 惩罚项

继续推导之前，需要明确惩罚项的形式。对于给定的树 \(T\)，用 \(T(x)=w_{q(x)}\) 表示其结构，其中 \(w\) 是某个叶节点的输出值，\(q(\cdot)\) 是把输入映射到最终叶节点的函数。图 6.5 展示了这种编码方式：函数 \(q\) 决定输入经过的路径，向量 \(\textbf{w}=w_i\) 则记录各终端叶节点的输出值。

图 6.5：编码决策树：结构与节点和叶值之间的分解。

以 \(l=1,\dots,L\) 表示树的叶节点索引。在 XGBoost 中，树的复杂度定义为： \[\Omega(T)=\gamma L+\frac{\lambda}{2}\sum_{l=1}^Lw_l^2,\] 其中：

  • 第一项惩罚叶节点总数；
  • 第二项惩罚叶节点输出值的大小，这有助于降低方差。

第一个惩罚项限制树的深度，第二个惩罚项则收缩最新一棵树带来的调整幅度。

6.4.3 聚合

现在把目标函数的两部分（损失项和惩罚项）合并起来。以 \(I_l\) 表示落入叶节点 \(l\) 的样本索引集合，则
\[\begin{align*} O&= 2\sum_{i=1}^I\left\{ -y_iT_J(\mathbf{x}_i)+m_{J-1}(\mathbf{x}_i) T_J(\mathbf{x}_i))+\frac{T_J(\mathbf{x}_i)^2}{2} \right\} + \gamma L+\frac{\lambda}{2}\sum_{l=1}^Lw_l^2 \\ &=2\sum_{i=1}^I\left\{- y_iw_{q(\mathbf{x}_i)}+m_{J-1}(\mathbf{x}_i)w_{q(\mathbf{x}_i)})+\frac{w_{q(\mathbf{x}_i)}^2}{2} \right\} + \gamma L+\frac{\lambda}{2}\sum_{l=1}^Lw_l^2 \\ &=2 \sum_{l=1}^L \left(w_l\sum_{i\in I_l}(-y_i +m_{J-1}(\mathbf{x}_i))+ \frac{w_l^2}{2}\sum_{i\in I_l}\left(1+\frac{\lambda}{2}\right)\right)+ \gamma L \end{align*}\]
该函数具有 \(aw_l+\frac{b}{2}w_l^2\) 的形式，其最小值为 \(-\frac{a^2}{2b}\)，在 \(w_l=-a/b\) 处取得。因此，以 #（·）表示集合的基数，即集合中的元素个数，有 \[\begin{align} \tag{6.5} \mathbf{\rightarrow} \quad w^*_l&=\frac{\sum_{i\in I_l}(y_i -m_{J-1}(\mathbf{x}_i))}{\left(1+\frac{\lambda}{2}\right)\#\{i\in I_l\}}, \text{ so that} \\ O_L(q)&=-\frac{1}{2}\sum_{l=1}^L \frac{\left(\sum_{i\in I_l}(y_i -m_{J-1}(\mathbf{x}_i))\right)^2}{\left(1+\frac{\lambda}{2}\right)\#\{i\in I_l\}}+\gamma L, \nonumber \end{align}\] 这里明确写出了目标函数对 \(q\)（树结构）和 \(L\)（叶节点数）的依赖关系。此时，树的整体形态仍有待确定。

6.4.4 树结构

最后一个问题是树结构。先回顾简单回归树：每个节点的输出值等于该节点（或区域）内标签的平均值。提升法为了降低损失而加入新树时，节点输出值必须采用不同的计算方式，这正是式 (6.5) 的作用。

不过，迭代构建新树的过程仍与简单树相似：逐一检验候选特征，选择能使每次分裂后的目标函数最小的特征。余下的问题是树应有多深、何时停止生长。具体做法如下：

  • 逐个节点进行；
  • 对每个节点，根据目标函数判断分裂是否有益：\[\text{Gain}=\frac{1}{2}\left(\text{Gain}_L+\text{Gain}_R-\text{Gain}_O \right)-\gamma\]
  • 每一部分的增益根据相应区域（节点）内的样本计算：\[\text{Gain}_\mathcal{X}= \frac{\left(\sum_{i\in I_\mathcal{X}}(y_i -m_{J-1}(\mathbf{x}_i))\right)^2}{\left(1+\frac{\lambda}{2}\right)\#\{i\in I_\mathcal{X}\}},\] 其中 \(I_\mathcal{X}\) 是区域 \(\mathcal{X}\) 内的样本索引集合。

\(\text{Gain}_O\) 是分裂前原节点的增益，\(\text{Gain}_L\) 和 \(\text{Gain}_R\) 分别是分裂后左右子节点的增益。上式中的 \(-\gamma\) 来自叶节点数的变化：一个旧叶节点被两个新叶节点替代，净增加一个叶节点，因此 \(\Delta L =1\)，相应惩罚为 \(\gamma\)。

最后，XGBoost 还使用学习率：每棵新树都乘以缩放因子 \(\eta\)，其中 \(\eta \in (0,1]\)。也就是说，每一步加入的新树 \(T_J\) 的输出都会乘以 \(\eta\)。这种收缩十分重要，因为直接叠加大量已优化的树，很容易对训练样本过拟合。

6.4.5 扩展

XGBoost 还提供若干机制，以进一步防止提升树过拟合。树的数量足够多时，集成模型可以很好地拟合训练样本，却未必能在样本外保持良好的泛化能力。

受 Srivastava et al. (2014) 开创性工作的启发，Rashmi and Gilad-Bachrach (2015) 提出了 DART（Dropout for Additive Regression Trees）。其思路是在训练期间随机暂时舍弃一定数量的树。完整参数说明见 https://xgboost.readthedocs.io/en/latest/tutorials/dart.html；下面的第一个示例使用 10% 的 dropout 比率。

单调约束是 XGBoost 和 LightGBM 都支持的另一项功能。有时，我们预期某个特征对标签具有单调影响。例如，如果坚信动量效应，那么在股票横截面上，过去收益率越高，未来收益率也应越高。

由于分裂算法具有递归结构，可以根据指定特征决定某次分裂是否可接受。图 6.6 展示了算法的处理方式，其中所有分裂都基于同一个特征。第一次分裂较为简单，只需验证两个子节点的平均值是否按要求的方向排序。更深层的分裂则较复杂：上层各次分裂确定的平均值会为下层节点的平均值设定可接受区间。若某次分裂违反这些界限，算法便忽略该分裂，改用其他变量。

6.4.6 代码与结果

本节使用 XGBoost 软件包训练模型。其他选择包括 catboost、gbm、lightgbm，以及 h2o 自带的提升模型。与许多软件包不同，XGBoost 函数要求特定的调用语法和数据格式，因此第一步是按要求封装数据。

此外，考虑到训练可能耗时较长，我们依照 Coqueret and Guida (2020) 的建议缩减训练样本。这里只保留标签值最极端的 40% 观测，即最高 20% 与最低 20%，并使用较小的特征子集。本书所有关于提升树的代码示例都只用 7 个特征训练模型。

library(xgboost)                                                # The package for boosted trees
train_features_xgb <- training_sample %>% 
    filter(R1M_Usd < quantile(R1M_Usd, 0.2) | 
               R1M_Usd > quantile(R1M_Usd, 0.8)) %>%            # Extreme values only!
    dplyr::select(all_of(features_short)) %>% as.matrix()       # Independent variable
train_label_xgb <- training_sample %>%
    filter(R1M_Usd < quantile(R1M_Usd, 0.2) | 
               R1M_Usd > quantile(R1M_Usd, 0.8)) %>%
    dplyr::select(R1M_Usd) %>% as.matrix()                      # Dependent variable
train_matrix_xgb <- xgb.DMatrix(data = train_features_xgb, 
                                label = train_label_xgb)        # XGB format!

第二步（可选）是确定要施加哪些单调约束。为简单起见，这里只对三个特征设置约束：

  1. 市值（负数，因为在规模异象下，大公司的收益率较小）；
  2. 市净率（负数，因为在价值异象下，被高估的公司收益率也较小）；
  3. 过去一年的收益率（正向，因为在动量异象下，赢家的表现优于输家）。
mono_const <- rep(0, length(features))                   # Initialize the vector
mono_const[which(features == "Mkt_Cap_12M_Usd")] <- (-1) # Decreasing in market cap
mono_const[which(features == "Pb")] <- (-1)              # Decreasing in price-to-book
mono_const[which(features == "Mom_11M_Usd")] <- 1        # Increasing in past return

第三步是在格式化后的训练数据上训练模型。这里同时启用单调约束和 DART 功能（通过 rate_drop）。与随机森林类似，提升树也可以让每棵树只使用部分数据：按行随机抽取一部分样本，或按列保留一部分预测变量。这两项设置分别由函数参数 subsample 和 colsample_bytree 控制。

fit_xgb <- xgb.train(data = train_matrix_xgb,     # Data source 
              eta = 0.3,                          # Learning rate
              objective = "reg:squarederror",     # Objective function
              max_depth = 4,                      # Maximum depth of trees
              subsample = 0.6,                    # Train on random 60% of sample
              colsample_bytree = 0.7,             # Train on random 70% of predictors
              lambda = 1,                         # Penalisation of leaf values
              gamma = 0.1,                        # Penalisation of number of leaves
              nrounds = 30,                       # Number of trees used (rather low here)
              monotone_constraints = mono_const,  # Monotonicity constraints
              rate_drop = 0.1,                    # Drop rate for DART
              verbose = 0                         # No comment from the algo 
    )

6.4.7 样本权重

计算总损失时，还可以为不同样本分配权重，从而提高模型的灵活性： \[O=\underbrace{\sum_{i=1}^I\mathcal{W}_i \times \text{loss}(y_i,\tilde{y}_i)}_{\text{weighted error term}} \quad + \underbrace{\sum_{j=1}^J\Omega(T_j)}_{\text{regularization term (unchanged)}}.\]

在因子投资中，样本权重完全可以取决于特征值（\(\mathcal{W}_i=\mathcal{W}_i(\textbf{x}_i)\)）。例如，对某一特征 \(\textbf{x}^k\)，权重可以随特征值上升，使高特征值资产受到更多重视；若该特征是价值指标，这相当于相对成长股更偏重价值股。另一种做法是让特征值越极端，样本权重越大，使深度价值股和高成长股都获得较大权重。若特征服从均匀分布，可令 \(\mathcal{W}_i(x_i^k)\propto|x_i^k-0.5|\)：特征值位于中位数 0.5 的公司权重为 0，越接近 0 或 1，权重越大。为样本指定权重会有意识地使学习过程偏向某些观测，这与 Black and Litterman (1992) 框架中主观观点影响资产配置的方式相似；区别在于，这种调整早在投资组合选择之前就已作用于模型训练。

在 XGBoost 中，样本权重需要在创建 xgb.DMatrix 时指定：

inst_weights <- runif(nrow(train_features_xgb))               # Random weights
inst_weights <- inst_weights / sum(inst_weights)              # Normalization
train_matrix_xgb <- xgb.DMatrix(data = train_features_xgb, 
                                label = train_label_xgb,
                                weight = inst_weights)        # Weights!

后续各阶段都会使用这些预先指定的权重进行优化。由于节点内计算的是加权总损失，候选分裂点可能随之改变，式 (6.5) 中的终端叶节点输出值也会受到影响。

6.5 讨论

本章最后从投资组合构建的角度讨论预测模型的选择。正如第 2 章所述，机器学习信号只是构建投资策略的一个环节，最终仍须转化为投资组合权重。

从这一角度看，单棵树并非理想选择。树深通常设为 3 到 6，因此最多只有 8 到 64 个终端叶节点，而且各叶节点包含的样本数可能很不均衡。某个叶节点占全部样本 20% 到 30% 并不少见，这意味着预测时约有 20% 到 30% 的样本会得到完全相同的预测值。

另一方面，投资组合规则通常会规定固定的资产数量。若很多资产得到相同信号，就无法仅凭该信号从中筛选子集。例如，策略要求恰好持有 100 只股票，而 105 只股票的信号相同，模型便无法决定应选哪 100 只。此时必须结合外部信息，例如均值—方差配置中的协方差矩阵。

这也是更适合采用集成模型的原因之一。学习器数量足够多时（约 5 个往往已接近足够），不同资产通常会得到各自不同的预测值，从而可以根据信号区分资产，只选择信号最有利的标的。在实践中，随机森林和提升树通常是更合适的选择。
