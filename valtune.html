10 模型验证与超参数调优

如第 5 章至第 11 章所示，机器学习模型在训练前需要由使用者指定一系列设置，包括参数取值（如学习率和惩罚强度）以及架构选择（如神经网络的结构）。不同的模型设计可能产生不同的预测，因此选择合适的设计十分关键。关于超参数调优如何影响模型表现，可参阅 Probst, Bischl, and Boulesteix (2018)。神经网络和提升树等模型的自由度很高，要找到合适的超参数并不容易。本章将讨论这些问题，但读者需要明白：构建良好的模型没有捷径。一个有效的模型往往需要投入大量时间，并经过多轮迭代才能得到。

10.1 模型评估指标

训练前设定的参数称为超参数。要选择合适的超参数，首先必须定义衡量机器学习模型表现的指标。机器学习任务通常分为两类：预测数值的回归任务，以及预测类别的分类任务。在介绍常见的评估指标之前，我们先提及 J. Li, Liao, and Quaedvlieg (2020) 提出的一种计量经济学方法。作者建议在给定某个外部变量的条件下，比较预测方法与指定基准的表现。这样可以判断模型在哪些经济环境中优于基准。该检验的完整实现较为复杂，感兴趣的读者可参阅原文中的推导。

10.1.1 回归分析

回归任务中的预测误差通常可以直接衡量。最常用的是 \(L^1\) 范数和 \(L^2\) 范数，二者都容易计算和解释。后者对应的均方根误差（RMSE）处处可微，但直观性稍弱，而且会给予异常值更大的权重；前者对应的平均绝对误差（MAE）表示预测值与已实现值之间的平均距离，但在误差为零处不可微。其定义为 \[\begin{align} \tag{10.1} \text{MAE}(\textbf{y},\tilde{\textbf{y}})&=\frac{1}{I}\sum_{i=1}^I|y_i-\tilde{y}_i|, \\ \tag{10.2} \text{MSE}(\textbf{y},\tilde{\textbf{y}})&=\frac{1}{I}\sum_{i=1}^I(y_i-\tilde{y}_i)^2, \end{align}\]

RMSE 就是 MSE 的平方根。还可以在这些公式中加入权重 \(w_i\)，使不同样本具有不同的重要性。下面简要讨论 MSE。它是机器学习中最常见的损失函数，却未必最适合投资组合配置中的收益率预测。将平方损失展开后，可以得到三项：已实现收益率的平方、预测收益率的平方，以及二者的乘积；若两者均值为零，最后一项大致对应协方差。第一项由数据给定，模型无法改变；第二项控制预测值围绕零的离散程度；从资产配置者的角度看，第三项最值得关注。交叉项 \(-2y_i\tilde{y}_i\) 为负时对投资者有利：若两者均为正，说明模型识别出了有盈利潜力的资产；若两者均为负，说明模型识别出了较差的投资机会。真正的问题出现在 \(y_i\) 与 \(\tilde{y}_i\) 符号不同时。因此，相比 \(\tilde{y}_i^2\)，交叉项对投资决策更重要，但常见算法并不会单独针对这一项进行优化。21

MSE 和 RMSE 也广泛用于机器学习以外的预测误差评估。下面介绍另外几种用于衡量模型质量的指标。与线性回归类似，任何预测任务都可以计算 \(R^2\)： \[\begin{equation} \tag{10.3} R^2(\textbf{y},\tilde{\textbf{y}})=1- \frac{\sum_{i=1}^I(y_i-\tilde{y}_i)^2}{\sum_{i=1}^I(y_i-\bar{y})^2}, \end{equation}\] 其中 \(\bar{y}\) 是标签的样本均值。与经典回归中的 \(R^2\) 不同，这里的指标可以在测试样本而非训练样本上计算。此时，如果分子中的均方误差大于测试样本的有偏方差，\(R^2\) 可能为负。有些研究会省略分母中的均值 \(\bar{y}\)，例如 Gu, Kelly, and Xiu (2020b)。这样做相当于将模型预测与恒为零的预测进行比较。对于收益率预测，这一基准尤其合适：最朴素的预测就是收益率为零，而此时的 \(R^2\) 可以衡量模型是否优于该朴素基准。零预测通常比样本均值更适合作为基准，因为样本均值高度依赖所选时期。此外，省略分母中的 \(\bar{y}\) 会使分母减小，从而令 \(R^2\) 更保守。

除上述基本指标外，还有一些扩展指标，其共同思路是在求平均之前先对误差进行变换。两个典型例子是平均绝对百分比误差（MAPE）和均方百分比误差（MSPE）。它们不直接使用原始误差，而是将误差除以待预测的实际值，因此结果以相对误差表示： \[\begin{align} \tag{10.4} \text{MAPE}(\textbf{y},\tilde{\textbf{y}})&=\frac{1}{I}\sum_{i=1}^I\left|\frac{y_i-\tilde{y}_i}{y_i}\right|, \\ \tag{10.5} \text{MSPE}(\textbf{y},\tilde{\textbf{y}})&=\frac{1}{I}\sum_{i=1}^I\left(\frac{y_i-\tilde{y}_i}{y_i}\right)^2, \end{align}\]

如有需要，还可以对 MSPE 开平方。当标签为正且取值可能很大时，原始误差也可能很大，此时可以通过变换压缩误差尺度。一种常用方法是均方根对数误差（RMSLE），定义如下：

\[\begin{equation} \tag{10.6} \text{RMSLE}(\textbf{y},\tilde{\textbf{y}})=\sqrt{\frac{1}{I}\sum_{i=1}^I\log\left(\frac{1+y_i}{1+\tilde{y}_i}\right)}, \end{equation}\]

当 \(y_i=\tilde{y}_i\) 时，该误差指标显然为零。

在讨论分类损失之前，我们再指出 MSE 的一个局限。MSE 是回归任务中使用最广泛的评估指标和优化目标，将其简单展开可得： \[\text{MSE}(\textbf{y},\tilde{\textbf{y}})=\frac{1}{I}\sum_{i=1}^I(y_i^2+\tilde{y}_i^2-2y_i\tilde{y}_i).\]

在这个求和式中，第一项由实际数据决定，模型无从改变，因此训练只会影响后两项。第二项反映预测值的离散程度，第三项则是实际值与预测值的交叉乘积。预测值 \(\tilde{y}_i\) 的波动固然重要，但在横截面预测中，第三项通常更关键：增大 \(y_i\tilde{y}_i\) 可以降低 MSE。当两者符号相同时，乘积为正，意味着模型判断对了投资方向，这正是投资者关心的结果。神经网络等算法允许自定义损失函数，因此，最大化 \(y_i\tilde{y}_i\) 之和可以作为普通二次损失优化的一种替代方案（实现示例见第 7.4.3 节）。

10.1.2 分类分析

分类任务的评估指标与数值预测任务有很大不同。许多指标专门针对二分类问题，不过其中一部分也可以推广到多分类模型。

下面按复杂程度逐步介绍这些指标，先区分“正类与负类”以及“预测正确与预测错误”。在投资场景中，可以把正类定义为收益率为正或高于基准，负类则表示相反情形。

二分类预测共有四种结果：实际为正且预测为正、实际为负且预测为负，这两种预测正确；实际为负却预测为正、实际为正却预测为负，这两种预测错误。相应的汇总指标定义如下：

  • 真阳性率：\(TP=I^{-1}\sum_{i=1}^I1_{\{y_i=\tilde{y}_i=1 \}},\)
  • 真阴性率：\(TN=I^{-1}\sum_{i=1}^I1_{\{y_i=\tilde{y}_i=0 \}},\)
  • 假阳性率：\(FP=I^{-1}\sum_{i=1}^I1_{\{\tilde{y}_i=1,y_i=0 \}},\)
  • 假阴性率：\(FN=I^{-1}\sum_{i=1}^I1_{\{\tilde{y}_i=0,y_i=1 \}},\)

按照惯例，正类编码为 1，负类编码为 0，以上四个比例之和为 1。它们对样本外投资结果的影响并不相同，如图 10.1 所示。该表也称为混淆矩阵。这里假设模型预测的是某种未来盈利能力指标：每一行表示模型的预测类别，每一列表示最终实现的类别。上方一行尤其重要，因为模型预测为正的资产可能会被纳入投资组合。如果资产后来确实表现良好（左上单元格），预测没有问题；如果模型判断错误（右上单元格），投资组合就会直接承受损失。

图 10.1：混淆矩阵：二分类结果汇总。

在两类错误中，第一类错误（假阳性）对投资者更危险，因为它会把实际表现不佳的资产纳入投资组合并直接造成损失。第二类错误（假阴性）意味着错过一次机会，影响通常较小。真阴性则是被模型正确排除在投资组合之外的资产。

由这四个基础比例还可以得到其他常用指标：

  • 准确率 = \(TP+TN\)，即预测正确的样本比例；
  • 召回率 = \(\frac{TP}{TP+FN}\)，衡量模型识别盈利策略或资产的能力（对应左列），也称敏感度或真正率（TPR）；
  • 精确率 = \(\frac{TP}{TP+FP}\)，表示被模型判为正类的资产中，实际表现良好的比例（对应上方一行）；
  • 特异度 = \(\frac{TN}{FP+TN}\)，表示实际负类中被正确识别的比例（对应右列）；
  • 假阳性率（fallout）= \(\frac{FP}{FP+TN}=1-\) 特异度，即实际负类被误判为正类的比例（对应右列）；
  • F1 分数：\(\mathbf{F}_1=2\frac{\text{recall}\times \text{precision}}{\text{recall}+ \text{precision}}\)，即召回率与精确率的调和平均数。

这些指标都落在 0 到 1 之间。除假阳性率外，数值越大通常表示模型表现越好。还存在错误发现率、错误遗漏率等指标，但使用较少，而且往往可以由上述指标直接推导。

另一个常用但更复杂的指标是 ROC 曲线下面积，简称 AUC。ROC 是 receiver operating characteristic 的缩写，通常译为“受试者工作特征”；这一名称源自信号检测理论。下面说明 ROC 曲线的构造方法。

如第 6 章和第 7 章所述，分类器通常输出一个样本属于各类别的概率，再根据概率大小确定预测类别。在二分类问题中，通常把正类概率高于 0.5 的样本判为正类。

实践中，0.5 未必是最佳阈值。例如，可以把正类概率低于 0.4 的样本判为负类，其余判为正类。于是，一个自然的问题是：改变决策阈值后，模型表现会怎样变化？ROC 曲线正是用来回答这个问题的。它以假阳性率为横轴、召回率（真正率）为纵轴，描绘阈值变化时两者之间的关系。

按照“预测概率高于阈值即判为正类”的惯例，当阈值为 0 时，所有样本都被判为正类，因此召回率和假阳性率均为 1；当阈值为 1 时，所有样本都被判为负类，因此二者均为 0。两个极端之间形成的轨迹称为 ROC 曲线，图 10.2 给出了示意图。随机分类器在召回率与假阳性率之间没有辨别能力，其 ROC 曲线是连接点 (0,0) 与 (1,1) 的对角线。为说明这一点，设样本中正类比例为 \(p\in (0,1)\)，分类器以概率 \(p'\in (0,1)\) 随机预测正类。由于真实类别与预测相互独立，有 \(TP=p'p\)、\(FP = p'(1-p)\)、\(TN=(1-p')(1-p)\) 和 \(FN=(1-p')p\)。代入上述定义可知，召回率与假阳性率都等于 \(p'\)。

图 10.2：ROC 曲线示意图。

ROC 曲线位于 45° 对角线上方，说明算法优于随机分类器。纵轴 \(y\) 可以理解为识别出优质策略的收益，横轴 \(x\) 则代表误选资产的代价，因此曲线越靠近左上角越好。理想分类器的 ROC 曲线依次经过 (0,0)、(0,1) 和 (1,1)。在点 (0,1) 处，假阳性率为 0、召回率为 1，既没有假阳性，也没有假阴性，模型的判断完全正确；点 (1,0) 则表示模型始终判断错误。

图 10.3 中的曲线非常接近 45° 对角线，说明该模型的分类能力与随机分类器相当，或者更准确地说，同样差。

比较模型时，直接比较整条曲线并不方便，因此通常用曲线下方的面积概括其信息，即 AUC。45° 对角线下的面积为 0.5，因为它恰好是单位正方形面积的一半。一个有辨别力的模型通常应有高于 0.5 的 AUC；完美分类器的 AUC 为 1。

最后讨论多分类数据。当输出标签包含两个以上类别时，评估会更复杂。仍然可以计算混淆矩阵，但矩阵维度更高，也更难解释；\(TP\)、\(TN\) 等二分类指标也需要采用并不统一的方式推广。此时，最简单的指标之一是式 (7.5) 定义的交叉熵。关于分类标签损失函数的更多内容，参见第 6.1.2 节。

10.2 验证

验证是指在模型投入真实环境（例如实盘交易）之前，对其进行测试和调优的阶段。这一步至关重要。

10.2.1 方差与偏差的权衡：理论

方差—偏差权衡是监督学习的核心概念之一。为说明这一概念，假设数据由以下简单模型生成： \[y_i=f(\textbf{x}_i)+\epsilon_i, \quad \mathbb{E}[\boldsymbol{\epsilon}]=0, \quad \mathbb{V}[\boldsymbol{\epsilon}]=\sigma^2,\]

而估计得到的模型为

\[y_i=\hat{f}(\textbf{x}_i)+\hat{\epsilon}_i. \]

对于一个未知样本 \(\textbf{x}\)，平均平方误差可分解为

\[\begin{align} \tag{10.7} \mathbb{E}[\hat{\epsilon}^2]&=\mathbb{E}[(y-\hat{f}(\textbf{x}))^2]=\mathbb{E}[(f(\textbf{x})+\epsilon-\hat{f}(\textbf{x}))^2] \\ &= \underbrace{\mathbb{E}[(f(\textbf{x})-\hat{f}(\textbf{x}))^2]}_{\text{total quadratic error}}+\underbrace{\mathbb{E}[\epsilon^2]}_{\text{irreducible error}} \nonumber \\ &= \mathbb{E}[\hat{f}(\textbf{x})^2]+\mathbb{E}[f(\textbf{x})^2]-2\mathbb{E}[f(\textbf{x})\hat{f}(\textbf{x})]+\sigma^2\nonumber\\ &=\mathbb{E}[\hat{f}(\textbf{x})^2]+f(\textbf{x})^2-2f(\textbf{x})\mathbb{E}[\hat{f}(\textbf{x})]+\sigma^2\nonumber\\ &=\left[ \mathbb{E}[\hat{f}(\textbf{x})^2]-\mathbb{E}[\hat{f}(\textbf{x})]^2\right]+\left[\mathbb{E}[\hat{f}(\textbf{x})]^2+f(\textbf{x})^2-2f(\textbf{x})\mathbb{E}[\hat{f}(\textbf{x})]\right]+\sigma^2\nonumber\\ &=\underbrace{\mathbb{V}[\hat{f}(\textbf{x})]}_{\text{variance of model}}+ \quad \underbrace{\mathbb{E}[(f(\textbf{x})-\hat{f}(\textbf{x}))]^2}_{\text{squared bias}}\quad +\quad\sigma^2 \nonumber \end{align}\]

在上述推导中，\(f(x)\) 是非随机的，而 \(\hat{f}(x)\) 是随机的。第二行还假设 \(\mathbb{E}[\epsilon(f(x)-\hat{f}(x))]=0\)；虽然这一常见假设并非始终成立，但在该假设下，平均平方误差由三部分组成：

  • 模型预测的方差；
  • 模型偏差的平方；
  • 不可约误差（与具体选择哪种模型无关）。

不可约误差不会随模型变化，因此关键在于尽量减小前两项之和。之所以称为方差—偏差权衡，是因为降低其中一项往往会提高另一项。我们需要判断：何时值得以一项的小幅上升，换取另一项更大幅度的下降。

这种权衡有多种直观表示方式，下面介绍两种。第一种是图 10.4 所示的射箭类比。最佳情形位于左上角：箭都集中在靶心附近，说明弓箭手平均瞄得准，而且每一箭的位置都很接近。最差情形位于右下角：箭的平均位置偏离靶心，说明偏差不为零，同时箭的分布也很分散，说明方差很大。

图 10.4：方差—偏差权衡的第一种表示。

机器学习中更常见的是另外两种情形：一是箭集中在一个很小的区域，但该区域偏离靶心，表示低方差、高偏差；二是箭总体围绕靶心分布，但彼此相距较远，表示低偏差、高方差。

第二种表示方式借助模型复杂度。最简单的是常数模型：无论输入如何，预测始终相同，例如恒等于训练集中标签的均值。这样的预测在测试集上往往偏离已实现值，因此偏差较大，但预测方差为零。另一端是叶节点数与样本数相同的决策树，其结构极为复杂。它的偏差可能较小，却未必足以抵消模型复杂度带来的方差上升。

图 10.5 展示了这种关系。图的左侧是简单模型，方差小但偏差大；右侧的复杂模型恰好相反。较好的模型通常位于两者之间，但最佳平衡点并不容易确定。

图 10.5：方差—偏差权衡的第二种表示。

岭回归是分析方差—偏差权衡时最容易处理的理论形式。22 其系数估计为 \(\hat{\mathbf{b}}_\lambda=(\mathbf{X}'\mathbf{X}+\lambda \mathbf{I}_N)^{-1}\mathbf{X}'\mathbf{Y}\)（见第 5.1.1 节），其中 \(\lambda\) 是惩罚强度。假设真实数据生成过程为线性形式 \(\textbf{y}=\textbf{Xb}+\boldsymbol{\epsilon}\)，其中 \(\textbf{b}\) 未知，误差项的方差为 \(\sigma^2\)，相关矩阵为单位矩阵，则有 \[\begin{align} \mathbb{E}[\hat{\textbf{b}}_\lambda]&=\textbf{b}-\lambda(\textbf{X}'\textbf{X}+\lambda \textbf{I}_N)^{-1} \textbf{b}, \\ \tag{10.8} \mathbb{V}[\hat{\textbf{b}}_\lambda]&=\sigma^2(\textbf{X}'\textbf{X}+\lambda \textbf{I}_N)^{-1}\textbf{X}'\textbf{X} (\textbf{X}'\textbf{X}+\lambda \textbf{I}_N)^{-1}. \end{align}\]

这意味着估计量的偏差为 \(-\lambda(\textbf{X}'\textbf{X}+\lambda \textbf{I}_N)^{-1} \textbf{b}\)。没有惩罚时，即经典回归情形下，偏差为零；当 \(\lambda \rightarrow \infty\)、模型趋于常数模型时，偏差收敛到某个有限值。还要注意，如果估计量无偏，则预测也无偏：\(\mathbb{E}[\textbf{X}(\textbf{b}-\hat{\textbf{b}})]=\textbf{0}\)。

在无约束回归中，系数估计值的方差为 \(\mathbb{V}[\hat{\textbf{b}}]=\sigma (\textbf{X}'\textbf{X})^{-1}\)。在式 (10.8) 中，\(\lambda\) 会缩小逆矩阵中各元素的幅度。总体而言，\(\lambda\) 越大，方差越小；当 \(\lambda \rightarrow \infty\)、模型成为常数模型时，方差趋于零。预测值的方差为 \[\begin{align*} \mathbb{V}[\textbf{X}\hat{\textbf{b}}]&=\mathbb{E}[(\textbf{X}\hat{\textbf{b}}-\mathbb{E}[\textbf{X}\hat{\textbf{b}}])(\textbf{X}\hat{\textbf{b}}-\mathbb{E}[\textbf{X}\hat{\textbf{b}}])'] \\ &= \textbf{X}\mathbb{E}[(\hat{\textbf{b}}-\mathbb{E}[\hat{\textbf{b}}])(\hat{\textbf{b}}-\mathbb{E}[\hat{\textbf{b}}])']\textbf{X}' \\ &= \textbf{X}\mathbb{V}[\hat{\textbf{b}}]\textbf{X} \end{align*}\]

因此，岭回归非常方便：只需一个参数，就可以直接调节方差与偏差之间的平衡。

下面用第 5 章训练的岭回归模型说明这一点。

10.2.3 过拟合的风险：原则

过拟合是机器学习中最重要的概念之一。模型一旦过拟合，样本外预测精度往往令人失望，这也是许多策略样本外失效的主要原因。因此，不仅要理解过拟合是什么，还要知道如何减轻它的影响。

关于过拟合及其对投资组合策略影响的近期研究，可参阅 Hsu et al. (2018)；该文建立在 White (2000) 的工作之上。两篇文献都不直接研究机器学习模型，但原理相同：面对任何给定的数据集，只要分析得足够深入，无论由人还是机器执行，几乎总能找到某种模式。关键在于这些模式是否只是偶然噪声。

图 10.8 用一个简单例子说明这一点。我们的目标是寻找把 x 映射到 y 的模型，训练数据以黑色小圆点表示。最简单的是只有一个参数的常数模型；加入截距和斜率两个参数后，蓝色直线已经拟合得相当不错。如果参数足够多，还可以构造一条穿过所有数据点的曲线，例如高阶多项式，图中红线便是一个例子。数据中有一个明显异常的点，而复杂模型为了贴合它发生了剧烈弯曲。

图 10.8：过拟合示意图：过度贴合训练数据通常并非好事。

图中又加入了一个浅绿色的新样本，它延续了其他样本的大致规律。简单模型虽然并不完美，误差也不可忽略，但复杂模型对应的误差（灰色虚线）约为前者的两倍。这个简化示例说明，过度贴合训练数据的模型会捕捉到其他数据集中不再出现的偶然特征。良好的模型应忽略这些噪声，抓住数据中更稳定、可重复的结构。

10.2.4 过拟合的风险：一些解决方案

最直接的防止过拟合方法，是谨慎使用高维神经网络或树集成等复杂模型。

模型复杂度通常用两个指标近似衡量：参数数量，以及参数幅度（通常用参数范数概括）。这两个指标并不完美，因为有些复杂模型可能只需少量参数，甚至参数值也很小；但它们至少直观且容易处理。不存在适用于所有模型的通用防过拟合方法，下面分别介绍几类机器学习模型的常见做法。

对于回归模型，有两种简单方法。第一是控制参数数量，也就是预测变量的数量。有时只选择部分特征更好，尤其当一些特征高度相关时；特征之间的绝对相关系数超过 70% 通常就会被视为过高。第二是通过 LASSO、ridge 或 elasticnet 加入惩罚，以收缩估计值的幅度，从而降低预测方差。

对于单棵树，降低过拟合风险的核心是限制叶节点数量，具体有多种方式。首先可以限制最大深度：若最大深度为 \(d\)，一棵树最多有 \(2^d\) 个终端节点，通常建议不要超过 \(d=6\)。rpart 中的复杂度参数 cp 也可以限制树的规模：只有当一次新分裂带来的损失下降至少达到 cp 时，才会执行该分裂。因此，cp 较大时树很难继续生长。rpart 还可以设置每个叶节点所需的最少样本数，以及允许节点继续分裂所需的最少样本数；这两个阈值越高，树就越难生长得复杂。

随机森林还可以控制森林中的树数。理论上（见 Breiman (2001)），增加树数不应提高过拟合风险，因为新树只会通过多样化降低总体误差；但考虑计算成本，实践中通常不建议超过 1,000 棵。另两个超参数是每个学习器使用的子样本规模，以及每次学习保留的特征数。它们对偏差—方差权衡没有简单直接的影响，却会影响模型的原始预测表现。子样本或特征数太少时，树学不到足够信息；特征数太多、接近全部特征时，各学习器接触的信息高度重叠，其预测之间的相关性可能过高。

提升树还有其他防止过拟合的手段。最明显的是学习率，它用 \(\eta \in (0,1)\) 缩减每棵新树的贡献。学习率过高时，算法学得太快，容易紧贴训练数据；学习率较低时，模型逐步学习，只要集成中有足够多的树，效果往往更好。因此，学习率与树数必须配合选择：两者都低，集成几乎学不到东西；两者都高，则容易过拟合。还可以惩罚叶节点分数和叶节点数量，防止模型过度追随训练样本中的细节。第 6.4.5 节介绍的单调性约束，也能给模型加入结构，使其只寻找符合指定方向的模式。

神经网络同样提供了多种防止过拟合的设置，包括学习率，以及对权重和偏置的范数施加惩罚。如果理论要求模型输入为正，还可以加入非负约束。最后，dropout 是直接减少网络有效参数数量的一种方法。

10.3 寻找合适的超参数

10.3.1 方法

假设模型运行前需要设定 \(p\) 个参数。最直接的做法是测试不同参数取值，再选择结果最好的组合。测试方法主要分为两类：彼此独立的搜索和按序更新的搜索。

独立搜索又可分为网格搜索（确定性搜索）和随机搜索。网格搜索的优点是能够均匀覆盖参数空间，不会有意遗漏某个角落；缺点是计算成本高。若每个参数至少测试五个值，总组合数便达到 \(5^p\)。当 \(p\) 较小（少于 3）且回测不太长时，这尚可处理；当 \(p\) 较大时，组合数会迅速变得难以承受。随机搜索则由使用者预先指定试验次数，再从每个参数的给定范围内随机抽取取值，通常采用均匀分布。它的缺点是可能漏掉参数空间中的某些区域，而最优解恰好位于这些区域。不过，Bergstra and Bengio (2012) 表明，随机搜索通常优于网格搜索。

网格搜索和随机搜索都可能把大量计算耗费在无关区域，因此并非最高效。已有若干参数点的试验结果后，更合理的做法是把后续搜索集中在最可能出现最优解的区域，并在每次测试新点后更新搜索策略。金融领域有关超参数调优的研究包括 S. I. Lee (2020) 和 Nystrup, Lindstrom, and Madsen (2020)。

另一种常用的按序搜索方法是贝叶斯优化（Bayesian optimization，BO）。其核心是学习过程的目标函数，记为 \(O\)；它可以是损失函数，也可以同时包含惩罚项和约束。为简化表述，这里把训练集和测试集视为固定，不再反复说明。待优化的变量是超参数向量 \(\textbf{p}=(p_1,\dots,p_l)\)，其中可以包含学习率、惩罚强度和模型数量等会影响 \(O\) 的设置。目标是求解

\[\begin{equation} \tag{10.9} \textbf{p}_*=\underset{\textbf{p}}{\text{argmin}} \ O(\textbf{p}). \end{equation}\]

困难在于，每计算一次 \(O(\textbf{p})\) 都可能代价高昂，因此必须谨慎选择下一组要尝试的 \(\textbf{p}\)。贝叶斯优化通常假设目标函数 \(O\) 服从高斯过程，并以超参数分量的线性组合近似 \(O\)，其中各分量记为 \(p_l\)。换言之，它在输入 \(\textbf{p}\) 与输出（响应变量）\(O\) 之间建立贝叶斯回归。代理模型估计完成后，\(O\) 的后验分布会告诉我们哪些区域更可能包含较优的超参数，从而指导下一组 \(\textbf{p}\) 的选择。

下一次试验由采集函数（acquisition function）选择。假设已经测试了 \(m\) 组超参数向量 \(\textbf{p}\)，相应试验点记为 \(\textbf{p}^{(m)}\)，当前最优参数为 \(\textbf{p}_m^*=\underset{1\le k\le m}{\text{argmin}} \ O(\textbf{p}^{(k)})\)。新点 \(\textbf{p}\) 只有在 \(O(\textbf{p})<O(\textbf{p}_m^*)\) 时才带来改进，也就是把目前已知的最小目标值进一步降低。该改进的后验期望为 \[\begin{equation} \tag{10.10} \textbf{EI}_m(\textbf{p})=\mathbb{E}_m[[O(\textbf{p}_m^*)-O(\textbf{p})]_+], \end{equation}\]

其中正部算子 \([\cdot]_+\) 表示，当 \(O(\textbf{p})\ge O(\textbf{p}_m^*)\) 时，改进为零。期望算子的下标 \(m\) 表示，它是根据 \(O(\textbf{p})\) 的后验分布计算的；该分布基于前 \(m\) 个试验样本 \(\textbf{p}^{(m)}\) 得到。于是，下一组最值得尝试的参数 \(\textbf{p}^{m+1}\) 为 \[\begin{equation} \tag{10.11} \textbf{p}^{m+1}=\underset{\textbf{p}}{\text{argmax}} \ \textbf{EI}_m(\textbf{p}), \end{equation}\] 即使期望改进（expected improvement，EI）最大的点。除 EI 外，也可以最大化其他采集函数，例如改进概率 \(\mathbb{P}_m[O(\textbf{p})<O(\textbf{p}_m^*)]\)。

整个迭代过程可以概括为：

  • 步骤 1：计算初始目标函数值 \(O(\textbf{p}^{(m)})\)，其中 \(m=1,\dots,M_0\)。
  • 步骤 2a：利用所有已有试验点更新 \(O\) 的后验分布。
  • 步骤 2b：选择下一组最优试验参数 \(\textbf{p}^{(m+1)}\)，见式 (10.11)。
  • 步骤 2c：计算新的目标函数值 \(O(\textbf{p}^{(m+1)})\)。
  • 步骤 3：按需要重复步骤 2a 至 2c，最后返回使目标函数最小的 \(\textbf{p}^{(m)}\)。

有关该方法数值实现的更多细节，可参阅 Snoek, Larochelle, and Adams (2012) 和 Frazier (2018)。

最后再介绍一种超参数调优思路。既然目标是 \(\underset{\textbf{p}}{\text{argmin}} \ O(\textbf{p})\)，自然可以利用 \(O\) 对 \(\textbf{p}\) 的敏感度。如果梯度 \(\frac{\partial O}{\partial p_l}\) 已知，就可以用梯度下降改善目标函数值。困难在于可靠梯度往往难以计算，而有限差分的计算成本也可能很高。尽管如此，Maclaurin, Duvenaud, and Adams (2015) 等方法已成功用于高维参数空间的优化。

Bouthillier and Varoquaux (2020) 调查了 2019 年两场主要人工智能会议上的论文，发现大多数研究都会进行超参数调优，其中最常见的是手动选择和网格搜索。

10.3.2 示例：网格搜索

下面通过寻找提升树的合适参数来说明网格搜索，并考察三个参数的影响：

  • eta：学习率；
  • nrounds：训练的树数；
  • lambda：权重正则化参数，通过叶节点权重（分数）的平方和惩罚目标函数。

首先用待测试的参数值构造网格。

考虑到网格搜索的计算成本，这里复用第 6 章特征数较少的数据集。为避免手写循环，我们借助 purrr 软件包提供的 R 函数式编程工具。下面定义的函数接收数据和参数，并返回算法的误差指标；这里用均方误差衡量不同超参数取值的影响。

grid_par <- function(train_matrix, test_features, test_label, eta, nrounds, lambda){
    fit <- train_matrix %>% 
        xgb.train(data = .,                            # Data source (pipe input)
                  eta = eta,                           # Learning rate
                  objective = "reg:squarederror",  # Objective function
                  max_depth = 5,                       # Maximum depth of trees
                  lambda = lambda,                     # Penalisation of leaf values
                  gamma = 0.1,                         # Penalisation of number of leaves
                  nrounds = nrounds,                   # Number of trees used
                  verbose = 0                          # No comment from algo
        )
    
    pred <- predict(fit, test_features)           # Predictions based on model & test values
    return(mean((pred-test_label)^2))             # Mean squared error
}

10.3.3 示例：贝叶斯优化

R 中有多个支持贝叶斯优化的软件包。这里使用通用性较强、但需要编写较多代码的 rBayesianOptimization。

                          test_label = testing_sample$R1M_Usd,    # Input for func: test label
                          eta, nrounds, lambda){                  # Input for func params
    fit <- train_matrix %>% 
        xgb.train(data = .,                       # Data source (pipe input)
                  eta = eta,                      # Learning rate
                  objective = "reg:squarederror", # Objective function
                  max_depth = 5,                  # Maximum depth of trees
                  lambda = lambda,                # Penalisation of leaf values
                  gamma = 0.1,                    # Penalisation of number of leaves
                  nrounds = round(nrounds),       # Number of trees used
                  verbose = 0                     # No comment from algo
        )

    pred <- predict(fit, test_features)           # Forecast based on fitted model & test values
    list(Score = -mean((pred-test_label)^2),      # Minus RMSE
         Pred = pred)                             # Predictions on test set
}

定义好目标函数后，即可将其传入贝叶斯优化器。

10.4 回测中的验证

回测中的验证比表面上更复杂。具体方法取决于预测模型是固定不变，还是会在每次再平衡时动态更新。

先讨论固定模型。此时只建立一个模型，再把它用于不同的测试时期。关于这种情形下应采用何种验证方法，学界仍有争论。通常，更合理的做法是按照时间顺序，在训练期之后的连续日期上测试模型，因为这最接近实盘中的信息流。

在一般机器学习任务中，常见做法是把数据分成 \(K\) 份，训练并测试 \(K\) 个模型：每次留出一份作为验证集，其余 \(K-1\) 份用于训练。这就是 K 折交叉验证（cross-validation，CV）。但对有时间顺序的金融数据，随机 K 折交叉验证通常并不适用，因为训练集可能包含测试时点之后的数据，相当于用未来信息检验过去。也有人主张采用经过专门设计的交叉验证，确保训练集与测试集在信息上不存在重叠，参见 De Prado (2018) 第 7.4 节和第 12.4 节。其前提是：如果收益率横截面的结构随时间保持稳定，那么只要消除了信息重叠，用较晚时期训练、在较早时期测试未必有问题。Schnaubelt (2019) 对多种验证方案进行了全面综述。

De Prado (2018) 举例讨论了模型面对未曾见过的危机时会如何反应。2008 年市场崩盘之后，至少连续 11 年没有发生同等规模的金融震荡。若想检验一个近期模型面对崩盘的表现，可以先用较近年份的数据（如 2015—2019 年）训练，再在 2008 年的若干时段（如不同月份）上测试。

固定模型的好处是验证较为简单：给定一组超参数，在一组日期上测试模型并评估其表现；对其他参数组合重复这一过程，再选择最优方案，或直接使用贝叶斯优化。

另一种做法是在每个再平衡日更新并重新训练模型。其出发点是收益率结构会随时间演变，动态模型可以捕捉较新的规律；代价是验证原则上也应在每个再平衡日重新执行。

回测通常涉及多个维度：
- 策略数量：可能是几十、几百，甚至更多；
- 交易日期数量：按月再平衡时可能有数百个日期；
- 资产数量：数百或数千；
- 特征数量：几十或几百。

即使拥有 GPU 等强大算力，在许多日期上训练大量模型仍然十分耗时；当超参数空间很大时，调优成本尤其高。因此，在整个样本外期间的每个交易日都重新验证模型并不现实。

一种可行方案是保留训练数据中较早的一段，在这个子样本上进行规模较小的验证，只选择有限的日期测试超参数。多数情况下，合适的超参数具有一定稳定性：某一日期表现良好的参数，在紧随其后的几个日期通常也可以接受。因此，完整回测可以沿用这些参数，并在每一期更新模型。不过，回测仍会消耗大量计算资源，因为每个再平衡日都必须用截至当时的最新数据重新训练模型。
