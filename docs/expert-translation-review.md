## 决策原则

1. 先逐段核对英文原意，不根据旧译文猜测。
2. 术语必须明确所指对象；英文形容词不得机械名词化。
3. 采用中文金融、统计和机器学习文献中的通行译法。
4. 首次出现使用完整术语，后文只有在指代明确时才可简称。
5. 保留原文的不确定性、条件和限制，不擅自强化结论。
6. 对同一概念的多个译名进行跨章节统一。

## 高风险术语

| 英文 | 审定译法 | 容易出现的问题 |
|---|---|---|
| instance / observation | 样本 / 观测 | 矩阵的一行称“样本”，具体资产—日期数据点称“观测”；不译为“实例” |
| prior distribution / prior probability | 先验分布 / 先验概率 | 不能不分对象一律写成“先验” |
| posterior distribution / posterior probability | 后验分布 / 后验概率 | 不能不分对象一律写成“后验” |
| posterior predictive distribution | 后验预测分布 | 不简写成对象不明的“后验预测” |
| likelihood / marginal likelihood | 似然函数 / 边际似然 | 不译为日常语义的“可能性” |
| credible interval / confidence interval | 可信区间 / 置信区间 | 两种统计解释不得混用 |
| estimate / estimator | 估计值 / 估计量 | 不应统一译为“估计” |
| factor exposure / factor loading | 因子暴露 / 因子载荷 | 依投资组合与回归语境区分 |
| expected / realized / forward return | 预期 / 已实现 / 未来收益率 | 时间含义必须明确 |
| rectified linear unit | 修正线性单元 | 不能泛化成“线性激活函数” |
| floor function | 向下取整函数 | “取整函数”未说明方向 |
