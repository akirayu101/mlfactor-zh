1 符号约定与数据

1.1 符号约定

本节给出全书统一采用的数学符号约定。

粗体符号表示向量和矩阵。矩阵用大写字母表示，向量用小写字母表示。 \(\mathbf{v}'\) 和 \(\mathbf{M}'\) 分别表示 \(\mathbf{v}\) 和 \(\mathbf{M}\) 的转置。\(\mathbf{M}=[m]_{i,j}\) 中，\(i\) 是行索引，\(j\) 是列索引。

全书同时采用两套相互对应的记号。第一套是机器学习记号，其中标签（也称输出、因变量或目标变量）\(\mathbf{y}=y_i\) 由特征 \(\mathbf{X}_i=(x_{i,1},\dots,x_{i,K})\) 的函数来近似。特征矩阵 \(\mathbf{X}\) 的维度为 \(I\times K\)：共有 \(I\) 个样本，每个样本对应矩阵的一行；每个样本有 \(K\) 个属性、特征、输入变量或预测变量，用作自变量或解释变量（这些术语在全书中互换使用）。有时，为简化记号，我们将 \(\textbf{X}\) 的一个样本（一行）记为 \(\textbf{x}_i\)，将 \(\textbf{X}\) 的一个特征列向量记为 \(\textbf{x}_k\)。

第二套是与第一套直接对应的金融记号。我们经常使用由价格数据计算得到的离散收益率 \(r_{t,n}=p_{t,n}/p_{t-1,n}-1\)。这里，\(t\) 是时间索引，\(n\) 是资产索引。除非另作说明，收益率均按一期计算；一期有时为一个月，有时为一年。可能产生歧义时，我们会另行说明收益率的记号。

与上述约定一致，收益率的观测日期数记为 \(T\)，资产数记为 \(N\)。资产的特征或属性记为 \(x_{t,n}^{(k)}\)：它表示公司或资产 \(n\) 的第 \(k^{th}\) 个属性在时刻 \(t\) 的取值。在堆叠记号中，\(\mathbf{x}_{t,n}\) 表示资产 \(n\) 在时刻 \(t\) 的特征向量。此外，\(\mathbf{r}_t\) 表示时刻 \(t\) 所有资产的收益率，\(\mathbf{r}_n\) 表示资产 \(n\) 在所有时期的收益率。收益率通常充当因变量，也就是机器学习中的标签。无风险资产的收益率记为 \(r_{t,f}\)。

大多数情况下，两套记号之间的对应关系如下。第 \(i\) 个样本对应面板数据中的一条资产—日期观测（\(t,n\)），即某个特定日期与某家特定公司。如果数据为没有缺失字段的完整矩形，则 \(I=T\times N\)。标签通常是根据未来某段时期计算的公司表现指标，特征则由公司在时刻 \(t\) 的属性构成。因此，用于因子投资的机器学习模型旨在确定一种映射关系，将公司在时刻 \(t\) 的特征映射到其未来表现。

对于常用的特殊矩阵，\(\mathbf{I}_N\) 表示 \((N\times N)\) 单位矩阵。

沿用概率论中的记号，我们以 \(\mathbb{E}[\cdot]\) 表示期望算子，以 \(\mathbb{E}_t[\cdot]\) 表示条件期望；相应的滤过 \(\mathcal{F}_t\) 表示时刻 \(t\) 可获得的全部信息。更准确地说，\(\mathbb{E}_t[\cdot]=\mathbb{E}[\cdot | \mathcal{F}_t]\)。\(\mathbb{V}[\cdot]\) 表示方差算子。根据上下文，概率简记为 \(P\)，有时也采用较繁复的记号 \(\mathbb{P}\)。概率密度函数（pdf）用小写字母（\(f\)）表示，累积分布函数（cdf）用大写字母（\(F\)）表示。我们将同分布写作 \(X \overset{d}{=}Y\)；这等价于在变量的支撑集上，对所有 \(z\) 都有 \(F_X(z)=F_Y(z)\)。对于随机过程 \(X_t\)，如果 \(X_t\) 的分布不随时间变化，即 \(X_t\overset{d}{=}X_s\)，则称其为平稳过程，其中 \(\overset{d}{=}\) 表示同分布。

渐近行为有时用常见的朗道记号 \(o(\cdot)\) 和 \(O(\cdot)\) 表示。符号 \(\propto\) 表示成比例关系：\(x\propto y\) 表示 \(x\) 与 \(y\) 成比例。对 \(x\) 求导时，采用标准记号 \(\frac{\partial}{\partial x}\)；计算全部偏导数（即梯度向量）时，则采用紧凑记号 \(\nabla\)。

在方程中，等式左端和右端可分别简写为 l.h.s. 和 r.h.s.。

最后列出几个函数：
- \(1_{\{x \}}\)：条件 \(x\) 的指示函数；\(x\) 为真时取 1，否则取零。
- \(\phi(\cdot)\) 和 \(\Phi(\cdot)\) 分别是标准正态分布的概率密度函数和累积分布函数。
- card\((\cdot)=\#(\cdot)\) 是基数函数的两种记号，用于计算作为函数参数给定的集合所含元素的数量。
- \(\lfloor \cdot \rfloor\) 是向下取整函数。
- 对于实数 \(x\)，\([x]^+\) 是 \(x\) 的正部，即 \(\max(0,x)\)。
- tanh\((\cdot)\) 是双曲正切函数：tanh\((x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}\)。
- ReLU\((\cdot)\) 是修正线性单元激活函数：ReLU\((x)=\max(0,x)\)。
- s\((\cdot)\) 表示 softmax 函数：\(s(\textbf{x})_i=\frac{e^{x_i}}{\sum_{j=1}^Je^{x_j}}\)，其中下标 \(i\) 指向量的第 \(i^{th}\) 个元素。

1.2 数据集

为保证可复现性，全书都以一个金融数据集为基础，通过实现示例来说明所介绍的概念。该数据集可从 https://github.com/shokru/mlfactor.github.io/tree/master/material 获取，包含 1,207 只在美国上市的股票（公司可能来自加拿大或墨西哥）的信息，时间范围为 1998 年 11 月至 2019 年 3 月。在每个时点，样本中的公司均由 93 个特征描述。这些属性涵盖多个方面：

  • 估值（盈利收益率、会计比率）；
  • 盈利能力和质量（净资产收益率）；
  • 动量和技术分析（过去收益率、相对强弱指标）；
  • 风险（波动率）；
  • 估计值（每股收益）；
  • 成交量和流动性（股票换手率）。

样本并非严格的矩形面板：数据点没有缺失，但公司数量及其属性均随时间变化。这使回测计算更加棘手，却也更贴近现实。

library(lubridate)                      # Activate the date management package
load("data_ml.RData")                   # Load the data
data_ml <- data_ml %>%

数据集直接给出四个标签：R1M_Usd、R3M_Usd、R6M_Usd 和 R12M_Usd，分别对应股票未来 1 个月、3 个月、6 个月和 12 个月的收益率。这些收益率是总收益率，即计入相应期间内可能支付的股息，因此比单纯的价格收益率更能反映实际投资收益。关于价格收益率与股息相分离所造成的影响，参见 Hartzmark and Solomon (2019) 的分析。这些标签位于数据集最后 4 列。下面给出其描述性统计量。

features <- colnames(data_ml[3:95]) # Keep the feature's column names (hard-coded, beware!)

原始标签（未来收益率）是数值型的，用于以预测标量实数为目标的回归练习。有时，任务也可能是预测类别（也称类），例如“买入”“持有”或“卖出”。为了进行这类分类分析，我们另外创建了类别型标签。

data_ml <- data_ml %>% 
    group_by(date) %>%                                   # Group by date
    mutate(R1M_Usd_C = R1M_Usd > median(R1M_Usd),        # Create the categorical labels
           R12M_Usd_C = R12M_Usd > median(R12M_Usd)) %>%
    ungroup() %>%
    mutate_if(is.logical, as.factor)

新标签是二元变量：原始收益率高于相应期限收益率的中位数时取 1（真），否则取 0（假）。因此，在每个时点，一半样本的标签为 0，另一半为 1：有些股票跑赢，有些股票跑输。

在机器学习中，模型先用一部分数据（训练集）拟合，再在另一部分数据（测试集）上检验，以评估其样本外表现。我们据此划分样本。

separation_date <- as.Date("2014-01-15")
training_sample <- filter(data_ml, date < separation_date)
testing_sample <- filter(data_ml, date >= separation_date)

我们还在内存中保留若干关键变量，例如资产标识符列表和矩形形式的收益率。为简化后者的计算，我们缩小投资范围，只保留观测数最多的股票。

stock_ids <- levels(as.factor(data_ml$stock_id)) # A list of all stock_ids
stock_days <- data_ml %>%                        # Compute the number of data points per stock
    group_by(stock_id) %>% summarize(nb = n()) 
stock_ids_short <- stock_ids[which(stock_days$nb == max(stock_days$nb))] # Stocks with full data
returns <- data_ml %>%                           # Compute returns, in matrix format, in 3 steps:
    filter(stock_id %in% stock_ids_short) %>%    # 1. Filtering the data
    dplyr::select(date, stock_id, R1M_Usd) %>%   # 2. Keep returns along with dates & firm names
    pivot_wider(names_from = "stock_id", 
                values_from = "R1M_Usd")         # 3. Put in matrix shape
