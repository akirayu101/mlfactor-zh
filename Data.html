4 数据预处理

本章介绍的方法主要面向金融应用。对于一般的非金融数据预处理，我们推荐两项参考资料：Boehmke and Greenwell (2019) 所著机器学习通论的第 3 章，以及 Kuhn and Johnson (2019) 专门讨论特征工程的著作。

4.1 了解数据

与任何定量研究一样，第一步是确保数据可信，至少应确认数据来自可靠的提供商。金融数据供应市场十分庞杂：既有成熟的提供商（如 Bloomberg、Thomson-Reuters、Datastream、CRSP 和 Morningstar），也有较新的提供商（如 Capital IQ 和 Ravenpack），还有专注于另类数据细分领域的提供商（完整列表见 https://alternativedata.org/data-providers/）。遗憾的是，据我们所知，尚无研究从数据可靠性角度系统评估众多此类提供商。

第二步是查看汇总统计量，包括取值范围（最小值和最大值）、均值和中位数。直方图或时间序列图的信息当然更丰富，但在高维情形下难以全面分析。不过，它们有时有助于追踪某只股票和/或某项特征的局部规律或错误。 除一阶矩外，方差、协方差和相关系数等二阶统计量也很重要，因为它们有助于识别共线性。当两个特征高度相关时，某些模型可能出现问题（如简单回归，参见第 15.1 节）。

预测变量往往多到无法逐一查看这些简单指标，但仍建议至少完成基本核验。为进一步简化分析，可以：

  • 关注预测变量的一个子集，例如与常见因子相关的变量（市值、市净率或账面市值比、动量（过去收益率）、盈利能力、资产增长和波动率）；
  • 追踪汇总统计量中的异常值，例如最大值与中位数之比或中位数与最小值之比看起来可疑的情形。

图 4.1 用箱线图展示了各特征与未来一个月收益率之间相关系数的分布。相关系数按日期、基于当日全部股票的横截面计算。大多数相关系数接近于零，但某些日期似乎出现了极端变化（黑色圆点表示异常值）。市值与收益率的相关系数中位数最低且为负，而波动率是唯一一个相关系数中位数为正的预测变量（这个特定例子似乎否定了低风险异象）。

data_ml %>% 
    dplyr::select(c(features_short, "R1M_Usd", "date")) %>%     # Keep few features, label & date
    group_by(date) %>%                                          # Group: dates!
    summarise_all(funs(cor(.,R1M_Usd))) %>%                     # Compute correlations
    dplyr::select(-R1M_Usd) %>%                                 # Remove label
    gather(key = Predictor, value = value, -date) %>%           # Put in tidy format
    ggplot(aes(x = Predictor, y = value, color = Predictor)) +  # Plot
    geom_boxplot(outlier.colour = "black") + coord_flip() + 
    theme(aspect.ratio = 0.6) + xlab(element_blank()) + theme_light()

图 4.1：与未来 1 个月收益率（标签）的相关系数箱线图。

更重要的是，在使用监督学习时（本书大部分情形均是如此），可以通过平滑后的条件均值进一步刻画某些特征与因变量之间的关系，因为条件均值反映了特征如何影响标签。条件均值具有深厚的理论基础。假设只有一个特征 \(X\)，我们希望建立模型 \(Y=f(X)+\text{error}\)，且变量均取实数值。使平均平方误差 \(\mathbb{E}[(Y-f(X))^2]\) 最小的函数 \(f\) 称为回归函数（参见 Hastie, Tibshirani, and Friedman (2009) 第 2.4 节）： \[\begin{equation} \tag{4.1} f(x)=\mathbb{E}[Y|X=x]. \end{equation}\]

图 4.2 给出了两个例子，其中因变量 \(Y\) 为未来一个月收益率。第一个例子使用过去一年的平均市值，第二个例子使用过去一年的波动率。两个预测变量均已作均匀化处理（参见下文第 4.4.2 节），使其在任一给定时点的资产横截面上服从均匀分布。因此，特征的取值范围为 \([0,1]\)，显示在图的 \(x\) 轴上。曲线周围的灰色带表示均值估计的 95% 置信区间。一般而言，当（i）可用数据点很多且（ii）这些点的离散程度较低时，置信带会较窄。

data_ml %>%                                                      # From dataset:
  ggplot(aes(y = R1M_Usd)) +                                     # Plot
  geom_smooth(aes(x = Mkt_Cap_12M_Usd, color = "Market Cap")) +  # Cond. Exp. Mkt_cap
  geom_smooth(aes(x = Vol1Y_Usd, color = "Volatility")) +        # Cond. Exp. Vol
  scale_color_manual(values=c("#F87E1F", "#0570EA")) +           # Change color
  coord_fixed(10) + theme_light() +                              # Change x/y ratio
  labs(color = "Predictor") + xlab(element_blank())

图 4.2：条件期望：作为特征平滑函数的平均收益率。

这两个变量对未来收益率的影响都接近单调。平均来看，收益率随市值增加而下降，从而印证了所谓的规模效应。波动率呈现的反向关系不那么明显：在波动率得分的前半段，曲线较为平坦；随后逐渐上升，尤其是在波动率最高的五分位组中，从而与低波动率异象相矛盾。

特征的一项重要经验性质是是否存在自相关。若某个预测变量具有较强的自相关性，那么在部分数据点缺失时，采用简单插补方法就有一定依据。自相关对于预测任务同样重要，我们将在下文第 4.6 节讨论。图 4.3 展示了逐只股票、逐项特征计算得到的自相关系数直方图。

autocorrs <- data_ml %>%                                         # From dataset:
  dplyr::select(c("stock_id", features)) %>%                     # Keep ids & features
  gather(key = feature, value = value, -stock_id) %>%            # Put in tidy format
  group_by(stock_id, feature) %>%                                # Group
  summarize(acf = acf(value, lag.max = 1, plot = FALSE)$acf[2])  # Compute ACF
autocorrs %>% ggplot(aes(x = acf)) + xlim(-0.1,1) +              # Plot
   geom_histogram(bins = 60) + theme_light()

图 4.3：样本特征自相关的直方图。

由于需要计算大量数值，上述代码块运行起来相当耗时。结果表明，预测变量普遍具有较强的自相关性：其中大多数的一阶自相关系数高于 0.80。

4.2 缺失数据

与其他实证学科一样，投资组合管理不可避免地会遇到缺失数据。这个问题已有充分研究，多部著作详细介绍了相应的解决方法（如 Allison (2001)、Enders (2010)、Little and Rubin (2014) 和 Van Buuren (2018)）。尽管研究人员仍在不断提出处理缺失观测的新方法（例如 Honaker and King (2010) 和 Che et al. (2018)），但我们认为，只要采取若干基本而审慎的防护措施，简单的启发式处理通常已经足够。

处理缺失数据主要有两种方式：删除和插补。删除法无须对数据作额外假设，但代价较高，尤其是仅因一个特征值缺失就删除整个样本时。插补通常更受青睐，但它依赖某些潜在假设，而这些假设可能并不成立。

插补的简化分类如下：

  • 一种基本做法是，用该股票该项特征的历史可用值中位数（或均值）进行插补。如果时间序列存在趋势，这种方法仍会改变原有趋势。此外，除非分别处理训练集和测试集，否则该方法可能产生前视偏差。
  • 在面向回测的时间序列场景中，最简单的做法是沿用前一期数值：若 \(x_t\) 缺失，就用 \(x_{t-1}\) 替代。多数情况下这种处理是合理的，因为当时只能获得过去的数据，而过去的数据按定义不含未来信息。但在某些特定情形下，这可能是很糟糕的选择（见下文注意事项）。
  • 也可以在资产横截面上计算中位数或均值。这相当于把缺失的特征值填到观测值分布的主体区域。如果缺失值很多，填充值会在特征分布的某一点形成概率质量，从而改变原始分布。这种插补的一个优点是不会产生前视偏差。
  • 许多方法依赖对数据生成过程的建模假设，包括非参数方法（Stekhoven and Bühlmann (2011) 和 Shah et al. (2014)，这些方法依赖随机森林，参见第 6 章）、贝叶斯插补（Schafer (1999)）、最大似然方法（Enders (2001)；Enders (2010)）、插值或外推，以及最近邻算法（Garcı́a-Laencina et al. (2009)）。更一般地，本节开头引用的四部著作详细介绍了许多此类插补方法。高级方法的计算开销要大得多。

需要特别注意以下几点：

  • 务必避免插值。对于按季度发布的会计数值或比率，绝不能采用线性插值，因为这种做法会使用未来信息。如果数据在 1 月和 4 月披露，那么对 2 月和 3 月进行插值就必须预先知道 4 月的数值，而在实时交易中，这一数值尚不可得。采用过去值通常更为妥当。
  • 不过，有些特征不应使用过去值插补。首先，不应照搬过去的收益率。默认情况下，将缺失的收益率指标设为零通常更合适，因为零往往接近均值或中位数。判断时可以考察特征在时间上的持久性：若特征高度自相关，且时间序列图呈平滑曲线（市值即是一例），那么使用过去值插补可能合理；否则应当避免。
  • 有些情形需要格外谨慎。考虑下面这个虚构的股息率样本：
表 4.1：按时间顺序插补面临的难题。
日期 原股息率 填充值
2015-02 NA 前一期数值（若存在）
2015-03 0.02 保持不变（无须填充）
2015-04 NA 0.02（前一期）
2015-05 NA 0.02（前一期）
2015-06 NA <= 问题！

这里的股息率按季度发布，例如在 3 月、6 月和 9 月发布，但 6 月的数值缺失。问题在于，我们无法判断它究竟因数据故障而缺失，还是因为公司在 6 月根本没有支付股息。因此，用过去值插补可能是错误的。虽然不存在完美的解决方案，但仍必须作出选择。对于股息数据，有三种方案：

  1. 沿用前一期数值。在 R 中，zoo 软件包的 na.locf() 函数能高效完成这项任务。
  2. 根据过去的观测进行外推（这与插值截然不同）：例如，估计历史数据的趋势并沿该趋势外推。
  3. 将数值设为零。这种做法颇具吸引力，但考虑到管理层通常会平滑股息，它可能并非最优选择（有关该主题的详情，参见 Leary and Michaely (2011) 和 Long Chen, Da, and Priestley (2012)）。对于持久性较强的时间序列，前两种方案可能更好。

可以通过测试比较各种方案的相对表现。记录这些设计选择也同样重要：选择很多，很容易遗忘，因此必须持续跟踪。在 ML 工作流中，数据准备脚本往往至关重要，因为它们并非只使用一次。

最后，R 中有许多用于数据插补的软件包，包括 Amelia、imputeTS、mice、mtsdi、simputation 和 VIM。感兴趣的读者可以进一步了解。

4.3 异常值检测

异常值检测同样有丰富的研究成果，既有综述（Hodge and Austin (2004)；Chandola, Banerjee, and Kumar (2009)；M. Gupta et al. (2014)），也有专著（Aggarwal (2013)；Rousseeuw and Leroy (2005)，其中第二部主要聚焦回归分析）。

同样，极其复杂的方法可能耗费大量精力，收益却很有限。只要在处理过程中做好记录，简单的启发式方法或许已经足够。这些方法通常依赖“硬”阈值：

  • 对于某项给定特征（必要时限定在某个时间区间），凡落在区间 \([\mu-m\sigma, \mu+m\sigma]\) 之外的观测都可视为异常值。其中，\(\mu\) 为样本均值，\(\sigma\) 为标准差；倍数 \(m\) 通常取自集合 \(\{3, 5, 10\}\)，当然，这种选择具有任意性。
  • 类似地，如果最大值超过第二大值的 \(m\) 倍，也可以将其归为异常值；分布另一端同理。
  • 最后，给定一个较小的阈值 \(q\)，凡落在 \([q,1-q]\) 分位数区间之外的数值都可视为异常值。

后一种思路因缩尾处理而广为人知。缩尾是将所有低于 \(x^{(q)}\) 的值设为 \(x^{(q)}\)，并将所有高于 \(x^{(1-q)}\) 的值设为 \(x^{(1-q)}\)。缩尾后的变量 \(\tilde{x}\) 为： \[\tilde{x}_i=\left\{\begin{array}{ll} x_i & \text{ if } x_i \in [x^{(q)},x^{(1-q)}] \quad \text{ (unchanged)}\\ x^{(q)} & \text{ if } x_i < x^{(q)} \\ x^{(1-q)} & \text{ if } x_i > x^{(1-q)} \end{array} \right. .\]

\(q\) 的取值范围通常为 \((0.5\%, 5\%)\)，最常用的是 1% 和 2%。

缩尾处理必须逐项特征、逐个日期执行。不过，从时间序列角度审视数据也很有帮助。例如，8,000 亿美元的市值乍看之下可能超出合理范围，但结合 Apple 的历史市值来看就未必如此。

最后需要强调，真实的异常值——即并非由数据提取错误造成的极端观测——很有价值，因为它们很可能携带重要信息。

4.4 特征工程

特征工程是投资组合构建流程中极其重要的一步。计算机科学领域常说“垃圾进，垃圾出”。因此，绝不能让用于资产配置的 ML 模型在设计不当的变量上训练。 感兴趣的读者可以参阅 Kuhn and Johnson (2019) 关于这一主题的近期著作；篇幅较短的学术参考文献则可见 Guyon and Elisseeff (2003)。

4.4.1 特征选择

第一步是选择特征。究竟应纳入哪些预测变量并不容易确定。例如，Bali et al. (2020) 表明，与固定收益相关的变量无助于预测股票收益率。一种启发式做法是选择学术文献和实务文献中经常提及的变量。当然，只采用常见特征可能不利于获取阿尔法，因为所有市场参与者都会将它们纳入考量。特征选择可以依据 A. Y. Chen and Zimmermann (2021) 等实证研究，也可以依据 Ohlson (1995) 等理论模型；Ohlson 的论文就是论证应将基本面数值作为自变量纳入预测模型的众多论文之一。

面对大量预测变量，滤除无用或冗余的外生变量通常是合理的。简单的启发式方法包括：

  • 计算全部特征的相关矩阵，并确保相关系数的绝对值不超过某个阈值（常用阈值为 0.7），以免冗余变量干扰学习器；
  • 进行线性回归，删除不显著的变量，例如 \(p\) 值高于 0.05 的变量；
  • 对特征集合进行聚类分析，每个聚类只保留一个特征（参见第 15 章）。

这些方法都较为简化，忽略了非线性关系。另一种办法是拟合决策树（或随机森林），只保留变量重要性较高的特征。第 6 章将介绍树模型，第 13 章将讨论变量重要性。

4.4.2 缩放预测变量

之所以需要预处理数据，是因为不同金融数据的量级差异很大：

  • 收益率的绝对值通常小于 1；
  • 股票波动率通常介于 5% 和 80% 之间；
  • 市值通常以某种货币的百万或十亿为单位；
  • 会计数值也是如此；
  • 会计比率的量纲可能并不一致；
  • 情绪等合成属性也各有其特点。

人们普遍认为，特征的单调变换对预测结果影响很小，但 Galili and Meilijson (2016) 表明事实并非总是如此（另见第 4.8.2 节）。因此，归一化方法的选择很可能会影响结果。

记原始输入为 \(x_i\)，变换后的数据为 \(\tilde{x}_i\)。常见的缩放方法包括：

  • 标准化：\(\tilde{x}_i=(x_i-m_x)/\sigma_x\)，其中 \(m_x\) 和 \(\sigma_x\) 分别为 \(x\) 的均值和标准差；
  • 将最小值—最大值缩放到 [0,1]：\(\tilde{x}_i=(x_i-\min(\mathbf{x}))/(\max(\mathbf{x})-\min(\mathbf{x}))\)；
  • 将最小值—最大值缩放到 [-1,1]：\(\tilde{x}_i=2\frac{x_i-\min(\mathbf{x})}{\max(\mathbf{x})-\min(\mathbf{x})}-1\)；
  • 均匀化：\(\tilde{x}_i=F_\mathbf{x}(x_i)\)，其中 \(F_\mathbf{x}\) 是 \(\mathbf{x}\) 的经验累积分布函数（c.d.f.）。此时，向量 \(\tilde{\mathbf{x}}\) 被定义为在 [0,1] 上服从均匀分布。

对于取值很大（如市值）且存在极端异常值的变量，有时可以先作对数变换，再进行缩放。含有负值的特征不能使用这种方法。

例如，在训练神经网络之前，通常建议把输入缩放到 [0,1]。本书使用的数据集以均匀化后的变量为基础：在每个时点，每项特征的横截面分布都在单位区间上服从均匀分布。在因子投资中，特征缩放必须逐日期、逐特征进行。这一点至关重要，因为它能确保每个再平衡日的预测变量具有相似的分布形态，并保留股票横截面上的信息。

均匀化有时采用另一种表述：在给定时点，对某项特征的取值排序，再用秩除以非缺失观测的数量。Freyberger, Neuhierl, and Weber (2020) 就采用了这种方法。Kelly, Pruitt, and Su (2019) 也进行了同样的处理，但随后将所有特征减去 0.5，使其取值落在 [-0.5,0.5] 内。

不应跨日期缩放特征。以市值为例，长期来看，尽管期间可能发生市场崩盘，市值仍会随时间上升。因此，跨日期缩放会使样本初期的数值偏小、样本末期的数值偏大，彻底改变并稀释特征所包含的横截面信息。

4.5 标签

4.5.1 简单标签

在构建投资组合策略时，可以用多种方式定义标签。最终目标当然是得到投资组合权重，但权重本身通常并不是标签的最佳选择。11

因子投资的常见标签如下：

  • 原始资产收益率；
  • 未来相对收益率（相对于某个基准，例如全市场指数或行业投资组合）。一种简单做法是用收益率减去横截面均值或中位数；
  • 正收益率（或高于指定阈值的收益率）的概率；
  • 跑赢基准的概率（在给定时间窗口内计算）；
  • 上述指标的二元版本：YES（跑赢）与 NO（跑输）；
  • 上述指标经风险调整后的版本：夏普比率、信息比率、MAR 或 CALMAR 比率（参见第 12.3 节）。

构造二元变量时，人们往往会把收益率与零比较，将样本分为盈利与不盈利两类。这种做法并不理想，因为它高度依赖市场所处时期：行情良好时，许多资产的收益率为正；市场崩盘时，只有少数资产能获得正收益率，因而会造成类别严重失衡。更合理的办法是把收益率与时点 \(t\) 的横截面中位数（或均值）比较并划分为两类。这样得到的是相对指标，两个类别也更加均衡。

正如本章后文将讨论的，这些选择仍留下了其他自由度：标签是否也应像特征一样重新缩放？计算表现指标时采用多长的时间期限最合适？

4.5.2 分类标签

在典型的 ML 分析中，当 \(y\) 作为未来表现的代理变量时，ML 模型会尽量缩小预测值与已实现值之间的距离。出于数学上的便利，通常使用误差平方和（\(L^2\) 范数），因为它的导数最简单，便于采用梯度下降法求解。

有时，与其直接关注收益率或夏普比率等原始表现代理指标，不如关注由这些指标推导出的离散投资决策。下面是一条简单的决策规则：

\[\begin{equation} \tag{4.2} y_{t,i}=\left\{ \begin{array}{rll} -1 & \text{ if } & \hat{r}_{t,i} < r_- \\ 0 & \text{ if } & \hat{r}_{t,i} \in [r_-,r_+] \\ +1 & \text{ if } & \hat{r}_{t,i} > r_+ \\ \end{array} \right., \end{equation}\] 其中 \(\hat{r}_{t,i}\) 是表现代理指标（如收益率或夏普比率），\(r_\pm\) 是决策阈值。当预测表现低于 \(r_-\) 时，决策为 -1（如卖出）；高于 \(r_+\) 时，决策为 +1（如买入）；处于两者之间时，模型既不十分乐观也不十分悲观，决策为中性（如持有）。表现代理指标当然也可以定义为相对于某个基准的表现，使决策与该基准直接挂钩。通常建议选择适当的阈值 \(r_\pm\)，使三个类别相对均衡，即各类包含数量大致相当的样本。

此时，最终输出既可以视为分类变量，也可以视为数值变量，因为它属于分类变量的一个重要子类——有序分类变量（ordinal variable）。若把 \(y\) 当作数值，就可以使用常规回归工具。

若将 \(y\) 视为无序的名义分类变量（nominal variable），则还需要额外处理，因为机器学习算法通常要求数值输入。为此，必须把类别重新编码为数字。最常用的映射称为独热编码（one-hot encoding）：把类别向量展开为一个稀疏矩阵，每一列对应一个类别，矩阵元素为 0 或 1；样本所属类别对应的列取值为 1。下表给出了一个简单示例。

在分类任务中，模型输出的维度更高：对每个样本，模型都会给出其属于各个类别的概率。正如第 6 章和第 7 章将介绍的，softmax 函数可以方便地处理这一问题。

从资产配置角度看，分类预测并不一定容易使用。对于多空投资组合，+1 或 -1 信号可以确定仓位方向。对于只做多投资组合，有两种可能的方案：（i）使用二元类别，即纳入或不纳入投资组合；（ii）根据预测结果调整权重：预测为 -1 时权重为零，预测为 0 时权重为 0.5，预测为 +1 时配置完整权重。之后还需将权重归一化，以满足预算约束。

4.5.3 三重屏障法

最后介绍 De Prado (2018) 提出的一种高级标签构造方法。其思路是考虑交易策略的完整动态过程，而不是只看一个简单的表现代理指标。这样扩展的理由在于，资产管理人经常设置损益触发条件：收益达到一定水平时获利了结，亏损达到一定程度时退出止损。策略启动时会设定三道屏障（见图 4.4）：

  • 一道位于资产当前价格之上（洋红色线），表示合理的预期利润；
  • 一道位于资产当前价格之下（青色线），作为止损信号，避免出现巨额负收益；
  • 最后一道用于确定策略期限，期限届满后策略即终止（黑线）。

若策略触及第一道（第二道）屏障，输出分别为 +1（-1）；若触及最后一道屏障，输出为零，或者取 -1 与 +1 之间的某个线性插值，以表示终值相对于两道水平屏障的位置。该方法的计算开销大得多，因为它需要评估每个样本的完整轨迹。不过，它也被认为更贴近现实，因为交易策略通常会设置止损等自动触发条件。

4.5.4 过滤样本

机器学习的主要挑战之一，是提取尽可能多的信号。这里的信号是指在样本外仍然成立的规律。直觉上，数据越多，似乎能提取的信号也越多。但一般而言，这并不成立，因为更多数据也意味着更多噪声。看似反常的是，筛选训练样本反而可能提高模型表现。Fu et al. (2018)、Guida and Coqueret (2018a) 和 Guida and Coqueret (2018b) 都成功应用了这一思路。

Coqueret and Guida (2020) 研究了为什么较小的样本可能使一类特定的 ML 算法——决策树（见第 6 章）——取得更高的样本外准确率。我们重点考察一种特定筛选方法：剔除取值不极端的标签（如收益率），只保留最低的 20% 和最高的 20%，删除分布中间的大部分样本。这样做会从两个方面改变树的结构：
- 分裂点发生变化时，总会更靠近分裂变量的分布中心，因而所得节点更均衡，也可能更稳健；
- 分裂变量的选择有时会偏向那些对标签具有单调影响的特征。
这两项性质都值得期待。第一项降低了模型拟合到小规模、可能只是偶然形成的样本组的风险；第二项提高了那些在整体上更有助于解释收益率的特征的重要性。不过，筛选不能过度。如果不再保留两端各 20% 的观测，而是只保留各 10%，信号损失就会过于严重，模型表现也会恶化。

4.5.5 收益率期限

本小节讨论基于因子的机器学习模型中较少受到关注的问题之一：期限。在由 ML 驱动的完整资产配置工作流中，会涉及多个期限：标签期限、估计窗口（训练样本在时间上的跨度）和持有期。较早考察这些问题的一篇文献，是 Jegadeesh and Titman (1993) 关于动量的奠基性论文。作者根据过去 \(J=3, 6, 9, 12\) 个月的收益率计算投资组合盈利能力，并检验 \(K=3,6,9,12\) 个月这四种持有期。他们报告：“最成功的零成本（多空）策略根据过去 12 个月的收益率选择股票，然后持有投资组合 3 个月。”虽然这项研究完全没有使用机器学习，但其关于期限至关重要的结论或许也适用于更复杂的方法。事实上，这一问题一直受到广泛讨论，关于期限如何影响动量策略盈利能力的持续争论就是明证（例如参见 Novy-Marx (2012)、Gong, Liu, and Liu (2015) 和 Goyal and Wahal (2015)）。

使用 ML 算法时也应考虑这场争论（例如参见 Geertsema and Lu (2020)）。估计窗口和持有期将在本书第 12 章进一步讨论。本章关注的重点自然是标签期限。为便于说明，假设只有一个特征，那么从启发式角度看有四种组合：

  1. 波动型标签与波动型特征；
  2. 波动型标签与平滑型特征（高度自相关）；
  3. 平滑型标签与波动型特征；
  4. 平滑型标签与平滑型特征。

在其他条件相同的情况下，最后一种组合可能更可取，因为它更加稳健。12 这里的其他条件相同，是指每种情形下模型都能提取某种有意义的规律。两个缓慢变化的序列之间形成的规律，更有可能随时间持续。由于特征往往高度自相关（见图 4.3），将它们与平滑型标签结合可能是合理的。为说明这一点有多关键，本书大多数示例会有意使用未来 1 个月收益率，并展示相应结果往往并不理想。1 个月收益率的自相关性很弱，而 6 个月或 12 个月收益率的持久性更强，因而更适合作为标签。

从理论上也可以理解其中原因。为简化分析，假设单一特征 \(x\) 能够解释收益率 \(r\)：\(r_{t+1}=f(x_t)+e_{t+1}\)。若 \(x_t\) 高度自相关，且 \(e_{t+1}\) 中包含的噪声不太大，那么未来两期收益率 \((1+r_{t+1})(1+r_{t+2})-1\) 可能比 \(r_{t+1}\) 包含更多信号，因为它与 \(x_t\) 的关系会随时间延续并通过复利累积。因此，像 Matthew F. Dixon (2020) 那样，把记忆机制直接纳入建模函数也可能有益。下一节将讨论与自相关有关的一些实际问题。

4.6 处理持久性

虽然我们把特征工程和标签构造分为两个小节，但更明智的做法或许是将两者结合起来考虑。供 ML 算法处理的数据集应具备一项重要性质：特征与标签的持久性应当匹配。直观地说，标签 \(y_{t,n}\)（未来表现）与特征 \(x_{t,n}^{(k)}\) 的自相关模式不应相差过大。

一种有问题的情形是：数据集按月采样——这在资产管理行业并不少见——标签为月度收益率，而特征则基于风险或基本面属性。此时，标签的自相关性很弱，特征却往往高度自相关。在这种情况下，即使是最复杂的预测工具，也可能只是在特征之间反复权衡，最终产生大量噪声。在线性预测模型中，已知这种设定会使估计量产生偏差（参见 Stambaugh (1999) 的研究和 Gonzalo and Pitarakis (2018) 的综述）。

除其他更技术性的方案外，这个问题有两种简单的处理方法：要么增强标签的自相关性，要么消除特征的自相关性。需要再次指出，若要对线性模型作统计推断，并不建议采用第一种方法。从计量经济学角度看，两种方法都很容易实施：

  • 为增强标签的自相关性，可以计算更长时间窗口内的表现。例如，处理月度数据时，可以考虑一年期或两年期收益率。
  • 要消除自相关，最直接的办法是使用差分或变动量：\(\Delta x_{t,n}^{(k)}=x_{t,n}^{(k)}-x_{t-1,n}^{(k)}\)。这种做法还有一个优点：它在经济上也有合理含义。与特征的原始水平相比，特征的变动可能更能驱动未来表现。

当然，特征空间中可以同时包含持久性变量和波动型变量，前提是这种选择有经济逻辑支撑。

4.7 扩展

4.7.1 特征变换

通过简单操作就能扩展特征空间。其中一种操作是引入滞后项，即使用特征较早期的值，并假设特征对标签的影响具有一定记忆效应。这种做法主要适用于波动型特征；对持久性很强的特征再增加一层记忆可能有些多余。新变量定义为 \(\breve{x}_{t,n}^{(k)}=x_{t-1,n}^{(k)}\)。

在某些情况下，例如特征数量不足时，可以考虑特征之间的比值或乘积。市净率、账面市值比和负债权益比等会计比率，就是由原始特征构造出的、具有合理含义的函数。扩大特征集合未必一定有益，反而会增加过拟合风险，正如在线性回归中添加变量会机械地提高 \(R^2\) 一样。因此，这些选择必须具有经济意义。

另一种扩展特征空间的方法，是使用上文提到的变动量。情绪变化、账面市值比变化等都可能成为相关的预测变量，因为有时变化比水平本身更重要。此时，新预测变量为 \(\breve{x}_{t,n}^{(k)}=x_{t,n}^{(k)}-x_{t-1,n}^{(k)}\)。

4.7.2 宏观经济变量

最后讨论一个非常重要的问题：绝不能脱离数据所处的背景或环境来分析数据。用经典金融术语来说，特定模型很可能依赖整体经济环境，而这种环境通常由宏观经济指标来代理。在数据层面纳入这一因素的一种简单方法，是将特征乘以外生指标 \(z_{t}\)。此时，新的预测变量为 \[\begin{equation} \tag{4.3} \breve{x}_{t,n}^{(k)}=z_t \times x_{t,n}^{(k)} \end{equation}\] Gu, Kelly, and Xiu (2020b) 采用了这种方法：他们使用 8 个经济指标，并保留原始预测变量（\(z_t=1\)），使特征空间扩大到原来的 9 倍。

另一种纳入经济环境变化的方法是条件化工程。假设标签按公式 (4.2) 编码，则可以让阈值取决于某个外生变量。在市场动荡时期，可以考虑同时提高 \(r_+\)（买入阈值）和 \(r_-\)（卖出阈值），使标签更为保守：进入买入类别需要更高的收益率，同时更偏向空头头寸。动态阈值可以写成

\[\begin{equation} \tag{4.4} r_{t,\pm}=r_{\pm} \times e^{\pm\delta(\text{VIX}_t-\bar{\text{VIX}})}, \end{equation}\]

其中，\(\text{VIX}_t\) 为时点 \(t\) 的 VIX，\(\bar{\text{VIX}}\) 为某个均值或中位数。当 VIX 高于其平均水平、风险似乎正在上升时，阈值也随之提高。参数 \(\delta\) 用于调整修正幅度。上例假设 \(r_-<0<r_+\)。

4.7.3 主动学习

本节最后介绍主动学习。据我们所知，主动学习尚未广泛用于量化投资，但其基本思想颇具启发性，因此为求完整，我们用几段文字加以说明。

在一般的监督学习中，获取特征与获取标签的难度有时并不对称。例如，获取图像本身可能无需成本，但为图像内容添加“狗”“卡车”或“披萨”等标签却成本高昂，因为这需要人工标注。形式化地说，\(\textbf{X}\) 很便宜，对应的 \(\textbf{y}\) 却很昂贵。

面对成本约束，一种直接方案是采用贪心策略。在常规学习过程开始前，先用一个通常称为查询的筛选机制，决定哪些数据需要标注并用于训练；这一决定也可能与 ML 算法有关。标注由所谓的预言机完成，即掌握真实答案的主体，通常是人类。这种聚焦于信息量最大样本的技术称为主动学习。关于这一领域的详细介绍，可参阅 Settles (2009) 和 Settles (2012) 的综述；下文只作简要概述。“主动”一词是指学习器并非被动接受数据样本，而是主动参与选择用于学习的样本。

主动学习的一项主要区分，在于查询所依赖的数据源 \(\textbf{X}\)。一种常见情形是，原始样本 \(\textbf{X}\) 很大且尚未标注，学习器要求为其中的特定样本添加标签。另一种情形是，学习器能够自行模拟或生成 \(\textbf{x}_i\)。如果预言机无法识别机器生成的数据，就可能出现问题。例如，要标注字符和数字图像时，学习器可能生成不对应任何字母或数字的形状，预言机也就无法为其添加标签。

主动学习的关键问题之一是：学习器如何选择需要标注的样本？启发式答案是，选择能使学习效率最大化的观测。在二元分类中，一个简单标准是样本属于某个类别的概率。如果该概率远离 0.5，算法通常很容易选定一个类别，尽管选择仍可能出错。更值得关注的是概率接近 0.5 的情形：机器可能无法确定该样本所属类别。此时，让预言机提供真实标签会很有帮助，因为这能协助学习器处理尚难判断的配置。

其他方法会估计把某个新样本纳入训练集后能够获得的拟合效果，再对这一效果进行优化。回顾 Geman, Bienenstock, and Doursat (1992) 第 3.1 节讨论的偏差—方差权衡，对于训练数据集 \(D\) 和样本 \(x\)（为简便起见省略粗体），有 \[\mathbb{E}\left[\left.(y-\hat{f}(x;D))^2\right|\{D,x\}\right]=\mathbb{E}\left[\left.\underbrace{(y-\mathbb{E}[y|x])^2}_{\text{indep. from }D\text{ and }\hat{f}} \right|\{D,x\} \right]+(\hat{f}(x;D)-\mathbb{E}[y|x])^2,\] 其中，记号 \(f(x;D)\) 用来突出模型 \(\hat{f}\) 对数据集 \(D\) 的依赖，因为模型是在 \(D\) 上训练的。第一项不依赖 \(\hat{f}\)，因而是不可约的；所以只有第二项值得关注。对 \(D\) 的所有可能取值求平均，可得 \[\mathbb{E}_D\left[(\hat{f}(x;D)-\mathbb{E}[y|x])^2 \right]=\underbrace{\left(\mathbb{E}_D\left[\hat{f}(x;D)-\mathbb{E}[y|x]\right]\right)^2}_{\text{squared bias}} \ + \ \underbrace{\mathbb{E}_D\left[(\hat{f}(x,D)-\mathbb{E}_D[\hat{f}(x;D)])^2\right]}_{\text{variance}}\] 如果这一表达式的计算并不太复杂，学习器就可以查询使该权衡最小的 \(x\)。因此，平均而言，这个新样本将带来最佳的学习效果，以 \(L^2\) 误差衡量。除这一方法外，还有许多其他查询准则；这一方法本身的局限在于，它可能要求预言机标注无关样本。完整列表可参阅 Settles (2009) 第 3 节。

最后一个问题是：主动学习能否用于因子投资？一个直接的回答是，金融数据无法通过人工干预加以标注。因此，学习器无法自行模拟样本，再请求对应标签。一种可能方案是只向学习器提供 \(\textbf{X}\) 而不提供 \(\textbf{y}\)，并仅保留查询得到且具有相应标签的观测子集。从思路上看，这与 Coqueret and Guida (2020) 的做法相近，只不过查询不是由机器执行，而是由人类用户执行。该文表明，并非所有观测都包含同等数量的信号。与标签取极端值的样本相比，标签取“平均”值的样本平均而言似乎信息更少。

    norm_0_1 = norm_0_1(x),                     # [0,1] reduction
    unif = norm_unif(x)) %>%                    # Uniformisation
    gather(key = Type, value = value, -index)   # Putting in tidy format
ggplot(data_norm, aes(x = index, y = value, fill = Type)) +   # Plot!
    geom_col() + theme_light() + 
    facet_grid(Type~.)          # This option creates 3 concatenated graphs to ease comparison

最后，查看这些新变量的直方图。

ggplot(data_norm, aes(x = value, fill = Type)) + geom_histogram(position = "dodge")

从形状上看，绿色和红色分布都接近原始分布，改变的只是支撑集：最小值—最大值缩放确保所有数值都落在 \([0,1]\) 区间内。在原始分布和最小值—最大值缩放后的分布中，最小值附近（左侧）都出现了尖峰。按照均匀化的构造方式，这一尖峰会消失，因为数据点被均匀地分布到单位区间上。

4.8.2 重新缩放的影响：示例

为说明选择特定缩放方法会产生什么影响13，我们构造了一个包含 3 家公司和 3 个日期的简单数据集。

firm <- c(rep(1,3), rep(2,3), rep(3,3))             # Firms (3 lines for each)
date <- rep(c(1,2,3),3)                             # Dates
cap <- c(10, 50, 100,                               # Market capitalization
         15, 10, 15, 
         200, 120, 80)
return <- c(0.06, 0.01, -0.06,                      # Return values
            -0.03, 0.00, 0.02,
            -0.04, -0.02,0.00)
data_toy <- data.frame(firm, date, cap, return)     # Aggregation of data
data_toy <- data_toy %>%                            # Transformation of data
    group_by(date) %>%                            
    mutate(cap_0_1 = norm_0_1(cap), cap_u = norm_unif(cap))

表 4.3：简单示例的样本数据。
firm date cap return cap_0_1 cap_u
1 1 10 0.06 0.000 0.333
1 2 50 0.01 0.364 0.667
1 3 100 -0.06 1.000 1.000
2 1 15 -0.03 0.026 0.667
2 2 10 0.00 0.000 0.333
2 3 15 0.02 0.000 0.333
3 1 200 -0.04 1.000 1.000
3 2 120 -0.02 1.000 1.000
3 3 80 0.00 0.765 0.667

下面简要说明这组合成数据。假设各日期按时间顺序排列且相距很远：每个日期代表某一年，甚至某个十年的开端，但未来收益率按月计算。第一家公司极为成功，其市值在这段时期扩大到原来的 10 倍；第二家公司的市值大致稳定；第三家公司的市值则大幅下跌。若分别考察每家公司“局部”的未来收益率，会发现第一家和第三家公司的未来收益率与规模呈明显负相关，而第二家公司没有清晰规律。

逐个日期考察时，结论大体相似，但略有差异。

  1. 在日期 1，规模最小的公司收益率最高，另外两家公司的收益率为负；
  2. 在日期 2，规模最大的公司收益率为负，另外两家较小公司的收益率不为负；
  3. 在日期 3，收益率随公司规模增大而下降。

虽然这种关系并非始终完全单调，但规模与收益率之间似乎确有关联。就这个样本而言，投资规模最小的公司通常会是一项很好的策略。

下面查看简单回归的输出。broom 是 tidyverse 的组成软件包，特别适合整理回归输出。

lm(return ~ cap_0_1, data = data_toy) %>% # First regression (min-max rescaling)
    broom::tidy() %>% 
    knitr::kable(caption = 'Regression output when the independent var. comes 
                 from min-max rescaling',  booktabs = T)
表 4.4：自变量经最小值—最大值缩放后的回归输出。
term estimate std.error statistic p.value
(Intercept) 0.0162778 0.0137351 1.185121 0.2746390
cap_0_1 -0.0497032 0.0213706 -2.325777 0.0529421 

lm(return ~ cap_u, data = data_toy) %>%   # Second regression (uniformised feature)
    broom::tidy() %>%   
    knitr::kable(caption = 'Regression output when the indep. var. comes from uniformization',
                  booktabs = T)
表 4.5：自变量经均匀化后的回归输出。
term estimate std.error statistic p.value
(Intercept) 0.06 0.0198139 3.028170 0.0191640
cap_u -0.10 0.0275162 -3.634219 0.0083509

从最后一列的 p 值来看，第一次估计得到的市值系数的 p 值高于 5%（表 4.4），第二次估计则低于 1%（表 4.5）。这种差异可能源于变量的标准差：cap_0 和 cap_u 的标准差分别为 0.47 和 0.29。市值等变量的取值范围可能很大，即使缩放后仍可能高度离散。使用均匀化变量可以减小离散程度，从而有助于缓解这个问题。

需要注意的是，这是一把双刃剑：均匀化虽然可能有助于避免假阴性，但也可能导致假阳性。
