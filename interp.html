13 模型可解释性

本章介绍用于理解模型如何将输入转化为输出的技术。两本近作专门讨论这一主题，值得进一步阅读：Molnar (2019)（在线版见 https://christophm.github.io/interpretable-ml-book/）以及 Biecek and Burzykowski (2021)（在线版见 https://ema.drwhy.ai）。Belle and Papantonis (2020) 提供了相关综述；若希望阅读更入门、技术性较低的材料，可参阅 Patrick Hall and Gill (2019)。 本章仍以因子投资为主线，示例均围绕在金融数据上训练的机器学习模型展开。

用于解释机器学习模型的定量工具应满足两个基本条件：

  1. 能够提供有关模型行为的信息；
  2. 解释结果易于理解。

这类工具通常以图形呈现结果，便于读者快速理解模型的主要规律。

解释复杂机器学习模型时，最常见的区分是全局解释与局部解释：

  • 全局解释考察模型训练完成后，各项特征对预测的相对作用。它总结的是整个训练集上的平均规律。
  • 局部解释关注模型在某个具体样本及其邻域内的行为。通过对该样本附近的特征作小幅扰动，观察原模型如何响应，再用较简单的模型（如线性模型）作局部近似，就可以估计各项相关特征在原始样本附近影响的方向和大小。

Molnar (2019) 还给出了另一种分类：一类解释方法依赖特定模型，例如线性回归或决策树；另一类则适用于任意模型，即模型无关方法。下文仍按全局解释和局部解释组织内容。

除下文介绍的传统方法外，还可关注 Sirus（Bénard et al. (2021)）和 Rulefit（J. H. Friedman and Popescu (2008)）。这两种方法均有 R 实现。

13.1 全局解释

13.1.1 以简单模型作为代理

先看最简单的情形。在线性模型中， \[y_i=\alpha+\sum_{k=1}^K\beta_kx_i^k+\epsilon_i,\] 通常会从 \(\beta_k\) 的估计结果中提取以下信息：

  • \(R^2\)，用于衡量模型的整体拟合优度；当预测变量很多时，也可采用带惩罚的版本以防止过拟合。\(R^2\) 通常在样本内计算；
  • 估计值 \(\hat{\beta}_k\) 的符号，表示特征 \(x^k\) 对 \(y\) 影响的方向；
  • \(t\) 统计量 \(t_{\hat{\beta_k}}\)，用于衡量这种影响的强度。不论方向如何，绝对值较大的统计量通常意味着对应变量较重要。\(t\) 统计量还常在适当的分布假设下转换为 \(p\) 值。

后两项信息尤其有用：它们分别说明哪些特征更重要，以及各预测变量作用的方向。由此可以得到模型如何将特征映射为输出的简化描述。多数黑箱模型解释工具也遵循这一思路。

决策树可以直接画成树状结构，因此本身具有较强的可解释性，也常被用作简单、透明的参照模型。Vidal, Pacheco, and Schiffer (2020) 提出了一种将树集成压缩为单棵树的方法，目标是用更简单的模型复现复杂模型的行为。

更一般地，可以用简单模型近似复杂算法，构建所谓的代理模型。步骤如下：

  1. 使用特征 \(\textbf{X}\) 和标签 \(\textbf{y}\)
    训练原始模型 \(f\)；
  2. 训练一个更简单的模型 \(g\)，以特征 \(\textbf{X}\) 为输入，近似已训练模型 \(\hat{f}\) 的预测： \[\hat{f}(\textbf{X})=g(\textbf{X})+\textbf{error}\]

估计得到的 \(\hat{g}\) 用来说明原模型 \(\hat{f}\) 如何把特征映射为预测。下面使用 iml 软件包演示这一方法（参见 Molnar, Casalicchio, and Bischl (2018)），并以一棵深度为 2 的树作为代理模型。

library(iml)

                     data = training_sample %>% dplyr::select(features)) 
dt <- TreeSurrogate$new(mod, maxdepth = 2)
plot(dt)

13.1.2 特征重要性（基于树）

简单决策树的一大优点是可解释性强：它的图形结构清晰直观。与线性回归一样，简单树容易理解，不会像更复杂的机器学习工具那样受到“黑箱”质疑。

随机森林和提升树由多棵树组成，难以完整展示模型内部的全部决策过程。不过，模型训练完成后，仍可汇总某项特征对树结构形成过程的贡献，并将其作为特征重要性。

训练完成后，对每个非叶节点 \(n\)，都可以计算下一次分裂带来的增益 \(G(n)\)。同时也能确定该节点采用了哪项特征进行分裂。记 \(\mathcal{N}_k\) 为所有使用特征 \(k\) 分裂的节点集合，则该特征的全局重要性为 \[I(k)=\sum_{n\in \mathcal{N}_k}G(n),\] 通常还会重新缩放，使所有 \(k\) 对应的 \(I(k)\) 之和等于 1。此时，\(I(k)\) 衡量特征 \(k\) 在训练过程中降低损失的相对贡献。重要性越高，对预测的影响通常越大；这类特征往往出现在更靠近树根的位置。

下面考察第 6 章训练的三种树模型。先提取三个拟合对象中的特征重要性。不同模型对象的结构不同，对应的重要性向量名称也不同。

tree_VI <- fit_tree$variable.importance  %>%                        # VI from tree model
    as_tibble(rownames = NA) %>%                                    # Transform in tibble 
    rownames_to_column("Feature")                                   # Add feature column
RF_VI <- fit_RF$importance  %>%                                     # VI from random forest
    as_tibble(rownames = NA) %>%                                    # Transform in tibble 
    rownames_to_column("Feature")                                   # Add feature column
XGB_VI <- xgb.importance(model = fit_xgb)[,1:2]                     # VI from boosted trees
VI_trees <- tree_VI %>% left_join(RF_VI) %>% left_join(XGB_VI)      # Aggregate the VIs
colnames(VI_trees)[2:4] <- c("Tree", "RF", "XGB")                   # New column names
norm_1 <- function(x){return(x / sum(x))}                           # Normalizing function
VI_trees %>% na.omit %>% mutate_if(is.numeric,  norm_1) %>%         # Plotting sequence
    gather(key = model, value = value, -Feature) %>%
    ggplot(aes(x = Feature, y = value, fill = model)) + geom_col(position = "dodge") +
    theme(axis.text.x = element_text(angle = 35, hjust = 1))

图 13.2：基于树的模型的特征重要性。

上面代码中的 tibble 与数据框类似，可以视为更现代的数据框实现。 由于作图代码的筛选方式，图 13.2 需要谨慎解读。简单树按其结构只会让少数特征具有非零重要性；图中仅有市值、市净率和波动率三项。随机森林和提升树更复杂，会给更多预测变量分配一定的重要性。图中只保留了简单树使用的特征，并在选定特征子集后才作归一化。这样处理是为了统一尺度并控制图中变量数量，保证可读性。

不同模型依赖特征的方式并不相同。简单树最看重市净率，随机森林更依赖波动率，提升树则对市值赋予更高权重。

随机森林的一个典型特点是让更多特征有机会参与建模。每次分裂时随机抽取候选预测变量，使各项外生变量都有机会解释标签。与重要性集中在少数特征上的简单树相比，随机森林和提升树在预测变量之间分配的重要性通常更均衡。

13.1.3 特征重要性（模型无关）

特征重要性的概念也可扩展到非树模型。相关研究可参阅 Fisher, Rudin, and Dominici (2019) 所引文献。目标仍然相同：量化每项特征对模型学习的贡献。

一种通用做法是置换特征值：将某项特征在样本中的取值完全打乱，再观察模型表现如何变化。如果原特征对解释因变量很重要，打乱它与其他变量之间的对应关系后，模型损失应明显上升。

置换特征重要性的基本步骤如下：

  1. 在原始数据上训练模型，并计算基准损失 \(l^*\)；
  2. 依次处理每项特征 \(k\)：随机置换该特征的取值，保持其他特征不变，再用改变后的样本计算模型损失 \(l_k\)；
  3. 以差值 \(\text{VI}_k=l_k-l^*\) 或比率 \(\text{VI}_k=l_k/l^*\) 衡量特征重要性，并据此排序。

损失应在训练集还是测试集上计算，并没有唯一答案，需要分析者结合目的判断。 置换过程带有随机性，因此可重复多次并对重要性取平均，以提高结果的稳定性。该算法由 Molnar (2019) 开发的 iml R 软件包中的 FeatureImp() 函数实现。另一个可用的软件包是 vip，参见 Greenwell and Boehmke (Forthcoming)。
下面针对图 13.2 中的特征手动实现该算法。示例使用岭回归，并沿用第 5 章中的变量。第一步是在原始训练样本上计算损失。

fit_ridge_0 <- glmnet(x_penalized_train, y_penalized_train,                   # Trained model
                      alpha = 0, lambda = 0.01) 
l_star <- mean((y_penalized_train-predict(fit_ridge_0, x_penalized_train))^2) # Loss

接着依次置换各预测变量并计算损失。为节省计算时间，这里每项特征只置换一次。

l <- c()                                                             # Initialize
for(i in 1:nrow(VI_trees)){                                          # Loop on the features
    feat_name <- as.character(VI_trees[i,1])
    temp_data <- training_sample %>% dplyr::select(features)         # Temp feature matrix

        sample(temp_data[, which(colnames(temp_data) == feat_name)]
               %>% pull(1), replace = FALSE)

    l[i] <- mean((y_penalized_train-predict(fit_ridge_0, x_penalized_temp))^2) # = Loss

13.1.4 部分依赖图

部分依赖图（partial dependence plot，PDP）用于展示模型输出与某项特征取值之间的关系。该方法的早期论述可参阅 J. H. Friedman (2001) 第 8.2 节。

选定特征 \(k\)。我们希望考察特征 \(k\) 对已训练模型 \(\hat{f}\) 预测结果的平均影响。将特征分为两部分：目标特征 \(k\)，以及其余所有特征 \(-k\)；后者代表除 \(k\) 以外的全部特征。部分依赖函数定义为

\[\begin{equation} \tag{13.1} \bar{f}_k(x_k)=\mathbb{E}[\hat{f}(\textbf{x}_{-k},x_k)]=\int \hat{f}(\textbf{x}_{-k},x_k)d\mathbb{P}_{-k}(\textbf{x}_{-k}), \end{equation}\]

其中，\(d\mathbb{P}_{-k}(\cdot)\) 是除 \(k\) 外其余特征 \(\textbf{x}_{-k}\) 的多元分布。函数以目标特征值 \(x_k\) 为自变量，并对其他特征在其分布上的取值取平均，从而隔离出特征 \(k\) 对预测的平均影响。实际计算通常使用蒙特卡罗近似：

\[\begin{equation} \tag{13.2} \bar{f}_k(x_k)\approx \frac{1}{M}\sum_{m=1}^M\hat{f}\left(x_k,\textbf{x}_{-k}^{(m)}\right), \end{equation}\] 其中 \(\textbf{x}_{-k}^{(m)}\) 是从除 \(k\) 外其余特征的分布中抽取的独立样本。

理论上，PDP 可以同时考察多项特征。实际应用通常至多展示两项特征，此时可画成三维曲面，但计算量也会增加。

下面用专门用于模型可解释性的 iml 软件包演示该方法；也可使用 Greenwell (2017) 介绍的 pdp 软件包。待解释模型是第 6.2 节训练的随机森林。这里沿用该节中的变量，考察市净率对模型预测的影响。

library(iml)                                         # One package for interpretability
mod_iml <- Predictor$new(fit_RF,                     # This line encapsulates the objects
                         data = training_sample %>% dplyr::select(features))
pdp_PB = FeatureEffect$new(mod_iml, feature = "Pb")  # This line computes the PDP for p/b ratio
plot(pdp_PB)                                         # Plot the partial dependence.

图 13.4：随机森林模型市净率的部分依赖图。

图中，市净率对预测值的平均影响随其取值上升而下降。这与图 6.3 所示的收益率条件均值规律相近：P/B 较低时曲线快速下降，随后趋于平坦。较低的市净率通常对应估值较低的公司，因此其较高预期收益率与价值溢价一致。

关于 PDP 能否作因果解释，可参阅 Q. Zhao and Hastie (2020) 的理论讨论。该文说明，在满足相应条件时，PDP 的构造可以赋予模型输出关于特征的因果解释。

13.2 局部解释

全局解释考察特征对输出的 \(overall\)（整体）影响，局部解释则刻画模型在某个具体样本及其邻域中的行为。近年来，局部模型可解释性受到广泛关注，相关研究迅速增加。下面介绍其中最常用的几种方法。27

13.2.1 LIME

LIME（Local Interpretable Model-Agnostic Explanations，局部可解释的模型无关解释）最初由 Ribeiro, Singh, and Guestrin (2016) 提出。它希望在满足以下两项约束的同时，忠实描述模型行为：

  • 可理解性：解释只包含有限数量的变量，并以图形或文本等直观形式呈现，使结果容易理解；
  • 局部忠实度：解释应准确反映模型在待解释样本附近的行为。

设原始黑箱模型为 \(f\)，我们希望用可解释模型 \(g\) 近似它在样本 \(x\) 附近的行为。简单函数 \(g\) 来自候选模型集合 \(G\)。用 \(x\) 的局部邻域权重 \(\pi_x\) 表示“附近”的范围，并用 \(g\) 的复杂度 \(\Omega(g)\) 约束解释的简洁程度。LIME 求解 \[\xi(x)=\underset{g \in G}{\text{argmin}} \, \mathcal{L}(f,g,\pi_x)+\Omega(g),\] 其中，\(\mathcal{L}(f,g,\pi_x)\) 衡量 \(g\) 在 \(x\) 的局部邻域 \(\pi_x\) 内逼近原模型时产生的误差。惩罚项 \(\Omega(g)\) 衡量解释模型的复杂度，例如树的叶节点数或深度，或者线性回归所用预测变量的数量。

具体而言，\(x\) 的邻域权重可定义为 \(\pi_x(z)=e^{-D(x,z)^2/\sigma^2},\) 其中 \(D\) 是距离度量，\(\sigma^2\) 是尺度参数。当 \(z\) 离 \(x\) 越远时，权重越小。

关键在于损失函数。LIME 在 \(x\) 附近生成人工样本，并汇总简单模型对原模型输出的近似误差。为简化记号，假设 \(f\) 的输出为标量，则 \[\mathcal{L}(f,g,\pi_x)=\sum_z \pi_x(z)(f(z)-g(z))^2\] 误差按照它与原始样本 \(x\) 的距离加权，距离越近，权重越大。在最基本的实现中，候选集合 \(G\) 由线性模型组成。

图 13.5 简化展示了 LIME 的工作原理。

图 13.5：LIME 示意图。红色方框标出待解释的具体样本，五个新样本（三角形）用于拟合加权线性模型（灰色虚线）。

为便于说明，图中只考虑一维情形。黑点是原始训练样本，蓝线是训练后模型给出的平滑条件均值。红色方框标出待解释的具体样本。为了在它附近构建简单近似，先采样 5 个新点（红色三角形），再取得原模型在这些点上的预测，因此三角形都落在蓝线上。三角形大小表示权重，离待解释样本越近，权重越大。最后以加权最小二乘法拟合灰色虚线。该局部线性近似产生截距和斜率两个参数，二者都可用标准统计检验评估。

斜率的符号很重要。如果待解释样本更接近 \(x=0\)，局部斜率很可能接近于零，此时该预测变量在这一邻域内几乎不起作用。邻域样本数同样重要。图中只用了 5 个点，但实际中要获得稳健估计，通常需要约 1,000 个或更多样本。邻域样本过少会增大估计风险，使局部近似不够可靠。

下面给出实现示例，步骤如下：

  1. 使用训练数据拟合模型；
  2. 用 lime() 函数封装模型及数据；
  3. 通过 explain() 函数选取若干预测变量，查看它们对若干具体样本的局部影响。

先完成第一步，这里使用提升树模型。

library(lime)                              # Package for LIME interpretation
params_xgb <- list(                        # Parameters of the boosted tree
    max_depth = 5,                         # Max depth of each tree
    eta = 0.5,                             # Learning rate 
    gamma = 0.1,                           # Penalization
    colsample_bytree = 1,                  # Proportion of predictors to be sampled (1 = all)
    min_child_weight = 10,                 # Min number of instances in each node
    subsample = 1)                         # Proportion of instance to be sampled (1 = all)
xgb_model <- xgb.train(params_xgb,         # Training of the model
                       train_matrix_xgb,   # Training data
                       nrounds = 10)       # Number of trees

接着使用 lime() 和 explain() 函数完成第二、第三步。

explainer <- lime(training_sample %>% dplyr::select(features_short), xgb_model) # Step 2.
explanation <- explain(x = training_sample %>%                                  # Step 3.
                           dplyr::select(features_short) %>%
                           dplyr::slice(1:2),           # First two instances in train_sample 
                       explainer = explainer,           # Explainer variable created above 
                       n_permutations = 900,            # Nb samples for loss function
                       dist_fun = "euclidean",          # Dist.func. "gower" is one alternative
                       n_features = 6                   # Nb of features shown (important ones)
)
plot_features(explanation, ncol = 1)                    # Visual display

每张图解释一个具体样本，并同时给出两类信息：特征影响的方向和大小。颜色表示方向，蓝色为正、红色为负；矩形长度表示影响大小。

图左侧的数值区间表示计算局部近似时所对应的特征取值范围。

最后说明代码中距离函数的选择。距离用于衡量原始样本（待解释样本）与模拟样本之间的差异，并据此调整模拟样本预测的权重。本书数据均为数值型，因此欧几里得距离是自然选择：

\[\text{Euclidean}(\textbf{x}, \textbf{y})=\sqrt{\sum_{n=1}^N(x_n-y_n)^2}.\] 也可以采用曼哈顿距离： \[\text{Manhattan}(\textbf{x}, \textbf{y})=\sum_{n=1}^N|x_n-y_n|.\]

欧几里得距离和曼哈顿距离不能直接处理分类变量，此时可使用 Gower 度量（Gower (1971)）。它按特征类型分别处理，并且还能处理缺失值。对分类特征，取值相同记为 1，不同记为 0，即 \(1_{\{x_n=y_n\}}\)；对数值特征，以 \(1-\frac{|x_n-y_n|}{R_n}\) 衡量相似程度，其中 \(R_n\) 是该特征可取的最大绝对值。再把各特征的相似度汇总为总分。需要注意，这里实际使用的是相似度方向：分数接近 1 时，\(\textbf{x}\) 与 \(\textbf{y}\) 很接近；接近 0 时则相距较远。

13.2.2 Shapley 值

Shapley 值与 LIME 的做法不同，在思路上更接近 PDP。它源于合作博弈论（Shapley (1953)）。基本直觉是：删除某个变量后，如果模型质量、尤其是预测准确度明显下降，该变量就具有较高价值。

在投资领域，Shapley 值已被用于分解投资组合的风险或业绩贡献，参见 Shalit (2020)、Shalit (2020) 和 Moehle, Boyd, and Ang (2021)。

最简单的数值方法是从完整变量集中逐项删除变量，并比较预测能力。Shapley 值考察得更全面：对目标预测变量加入各种可能变量组合时的边际贡献进行加权平均。形式化定义为：

\[\begin{equation} \tag{13.3} \phi_k=\sum_{S \subseteq \{x_1,\dots,x_K \} \backslash x_k}\underbrace{\frac{\text{Card}(S)!(K-\text{Card}(S)-1)!}{K!}}_{\text{weight of coalition}}\underbrace{\left(\hat{f}_{S \cup \{x_k\}}(S \cup \{x_k\})-\hat{f}_S(S)\right)}_{\text{gain when adding } x_k} \end{equation}\]

\(S\) 是不包含特征 \(k\) 的任意特征子集，Card(\(S\)) 表示该子集的大小。
上式需要对模型 \(f\) 作相应处理，因为缺少部分特征时无法直接计算 \(f\)；对此存在多种处理方案。

当预测变量很多时，计算 Shapley 值可能非常耗时。J. Chen et al. (2018) 讨论了降低计算成本的近似方法。 Lundberg and Lee (2017) 则研究了 Shapley 值在模型可解释性中的扩展。

R 中可通过 iml 软件包计算 Shapley 值。与前面的 LIME 实现相比，这里有两项限制。第一，图中会显示全部特征，超过 20 项后通常难以阅读，因此需事先筛选特征。下面的代码采用第 1.2 节给出的精简预测变量列表。 第二，每次只能分析一个样本。

先拟合随机森林模型。

13.2.3 分解法

分解法（例如参见 Staniak and Biecek (2018)）结合了 PDP 与 Shapley 值的思想。其核心是式 (13.4) 定义的松弛模型预测，概念上接近式 (13.1)。区别在于，分解法作局部解释，只针对一个具体观测 \(x^*\)。为了衡量一组预测变量对 \(x^*\) 预测结果的影响，将特征分为固定集合 \(\textbf{k}\) 和自由集合 \(-\textbf{k}\)。当集合 \(\textbf{k}\) 中的预测变量固定为 \(x^*\) 的对应取值时，用下式作为估计模型 \(\hat{f}\) 平均预测的代理，其中固定值写作 \(x^*_{\textbf{k}}\)：

\[\begin{equation} \tag{13.4} \tilde{f}_{\textbf{k}}(x^*)=\frac{1}{M}\sum_{m=1}^M \hat{f}\left(x^{(m)}_{-\textbf{k}},x^*_{\textbf{k}} \right). \end{equation}\]

上式中的 \(x^{(m)}\) 可以是模拟样本，也可以是从数据集中抽取的样本。该记号表示：将待解释样本 \(x^*\) 的部分特征值代入每个模拟或抽取样本，具体代入哪些特征由索引集合 \(\textbf{k}\) 指定。当 \(\textbf{k}\) 包含全部特征时，\(\tilde{f}_{\textbf{k}}(x^*)\) 就等于原模型对待解释样本的预测 \(\hat{f}(x^*)\)；当 \(\textbf{k}\) 为空集时，它等于标签的样本均值，即常数预测。

我们关心的是特征 \(j\notin \textbf{k}\) 相对于数据点 \(x^*\) 和集合 \(\textbf{k}\) 的贡献：

\[\phi_{\textbf{k}}^j(x^*)=\tilde{f}_{\textbf{k} \cup j}(x^*)-\tilde{f}_{\textbf{k}}(x^*).\]

与 Shapley 值类似，该指标衡量把特征 \(j\) 加入预测变量集合后产生的平均影响。它依赖于给定集合 \(\textbf{k}\)，这与遍历全部排列的 Shapley 值不同。Staniak and Biecek (2018) 设计了一种逐步增加或减少集合 \(\textbf{k}\) 的贪心算法，避免穷举全部特征组合。该算法还有一个方便的性质：所有贡献之和等于模型预测值： \[\sum_j \phi_{\textbf{k}}^j(x^*)=f(x^*).\]

图 13.7 可以直观展示这一加总关系。

下面演示分解法的一种实现。为提高输出的可读性，只使用有限数量的特征训练随机森林。
