8 支持向量机

支持向量机（SVM）的思想可追溯到 Vapnik and Lerner (1963)；现代 SVM 体系则由 Boser, Guyon, and Vapnik (1992) 和 Cortes and Vapnik (1995) 在二分类问题中奠定，并由 Drucker et al. (1997) 推广到回归。关于其理论与实证性质的完整书目，可参阅 http://www.kernel-machines.org/books。SVM 问世后长期受到机器学习界重视；不过，随着神经网络兴起，它在计算机视觉等许多领域的主导地位已逐渐被取代。

8.1 用于分类的 SVM

机器学习中的复杂方法通常可以借助二分类图示直观说明，有些方法原本就是为二分类设计的，例如感知机。下面考虑只有两个特征的平面情形。图 8.1 的目标是找到一条决策边界，正确区分实心圆与空心方块。

图 8.1：包含支持向量的二元分类示意图。

模型用参数权重 \(\textbf{w}=(w_1,w_2)\) 组合两个特征，在平面上形成线性决策边界。图中给出三条候选边界。红线两侧都混有圆和方块，无法正确分类；蓝线与绿线都能把圆和方块完全分开，但二者的稳健性并不相同。

图上方的灰色星形代表一个待分类的新样本。若现有数据规律延续，它应被判为圆。蓝色边界会判断错误，绿色边界则判断正确。绿色实线两侧的灰色虚线围成一个没有训练样本落入的带状区域，这就是分类间隔。星形样本落在该区域内，因此不同决策边界可能给出不同预测。

两条虚线与决策边界平行，并经过两侧离边界最近、且被正确分类的样本。这些样本称为支持向量，也是该方法名称的由来。绿色边界的间隔明显大于蓝色边界。硬间隔 SVM 的核心，就是在训练样本全部正确分类的约束下使间隔最大；也就是说，在所有零训练误差的线性分类器中选择对扰动最稳健的一个。

更形式化地，若把圆编码为 +1、方块编码为 -1，一个满足硬间隔条件的线性模型应当满足：

\[\begin{equation} \tag{8.1} \left\{\begin{array}{lll} \sum_{k=1}^Kw_kx_{i,k}+b \ge +1 & \text{ when } y_i=+1 \\ \sum_{k=1}^Kw_kx_{i,k}+b \le -1 & \text{ when } y_i=-1, \end{array}\right. \end{equation}\]

这两个条件可合写为 \(y_i \times \left(\sum_{k=1}^K w_kx_{i,k}+b \right)\ge 1\)。决策边界到灰色虚线上支持向量的距离为 \(||\textbf{w}||^{-1}=\left(\sum_{k=1}^Kw_k^2\right)^{-1/2}\)。这是因为点 \((x_0,y_0)\) 到直线 \(ax+by+c=0\) 的距离为 \(d=\frac{|ax_0+by_0+c|}{\sqrt{a^2+b^2}}\)；在式 (8.1) 中，支持向量对应的分子为 1，分母则是 \(\textbf{w}\) 的范数。因此，最大化间隔等价于下面的最优化问题：

\[\begin{equation} \tag{8.2} \underset{\textbf{w}, b}{\text{argmin}} \ \frac{1}{2} ||\textbf{w}||^2 \ \text{ s.t. } y_i\left(\sum_{k=1}^Kw_kx_{i,k}+b \right)\ge 1. \end{equation}\]

为求解该问题，可构造如下拉格朗日函数（参见 Boyd and Vandenberghe (2004) 第 5 章）：

\[\begin{equation} \tag{8.3} L(\textbf{w},b,\boldsymbol{\lambda})= \frac{1}{2}||\textbf{w}||^2 + \sum_{i=1}^I\lambda_i\left(y_i\left(\sum_{k=1}^Kw_kx_{i,k}+b \right)- 1\right), \end{equation}\] 互补松弛条件意味着：要么 \(\lambda_i=0\)，要么 \(y_i\left(\sum_{k=1}^Kw_kx_{i,k}+b \right)= 1\)。因此，最终解只由一部分样本决定，它们就是支持向量。一阶条件要求拉格朗日函数对参数的导数为零： \[\frac{\partial L}{\partial \textbf{w}}L(\textbf{w},b,\boldsymbol{\lambda})=\textbf{0}, \quad \frac{\partial L}{\partial b}L(\textbf{w},b,\boldsymbol{\lambda})=0,\] 第一个条件给出： \[\textbf{w}^*=\sum_{i=1}^I\lambda_iu_i\textbf{x}_i.\] 这个解仍是特征的线性组合，但只有使式 (8.1) 取等号的样本会以非零系数进入解，也就是只有支持向量真正决定决策边界。

如果无论怎样选择参数，都不存在一条直线能把两类样本完全分开，那么硬间隔问题就没有可行解；这种数据称为线性不可分。实际数据通常属于这种情形。解决办法是在式 (8.1) 中加入松弛变量，允许个别样本落入间隔甚至被误分类：

\[\begin{equation} \tag{8.4} \left\{\begin{array}{lll} \sum_{k=1}^Kw_kx_{i,k}+b \ge +1-\xi_i & \text{ when } y_i=+1 \\ \sum_{k=1}^Kw_kx_{i,k}+b \le -1+\xi_i & \text{ when } y_i=-1, \end{array}\right. \end{equation}\]

其中，\(\xi_i\) 是非负的松弛变量，用于度量第 i 个样本对间隔约束的违反程度，使原本不可行的问题变得可行。图 8.2 展示了这种情形：不存在能够完美区分两类样本的线性边界。

图 8.2：SVM 二元分类示意图：线性不可分数据。

于是，软间隔 SVM 的优化问题变为： \[\begin{equation} \tag{8.5} \underset{\textbf{w},b, \boldsymbol{\xi}}{\text{argmin}} \ \frac{1}{2} ||\textbf{w}||^2+C\sum_{i=1}^I\xi_i \ \text{ s.t. } \left\{ y_i\left(\sum_{k=1}^Kw_k\phi(x_{i,k})+b \right)\ge 1-\xi_i \ \text{ and } \ \xi_i\ge 0, \ \forall i \right\}, \end{equation}\] 其中超参数 \(C>0\) 控制违反间隔约束的成本：\(C\) 越大，模型对松弛变量和误分类的惩罚越重，因而更强调训练集拟合。

此外，可通过非线性特征映射 \(\phi\) 变换输入 \(x_{i,k}\)，从而处理直线无法描述的复杂边界（见图 8.3）。在对偶问题中，直接用核函数计算映射后特征的内积，无须显式构造高维映射，这就是核技巧。常见选择包括多项式核、径向基函数核和 sigmoid 核。模型可用标准的约束二次规划方法求解。训练得到参数权重 \(\textbf{w}\) 与偏置 \(b\) 后，对于新向量 \(\textbf{x}_j\)，计算 \(\sum_{k=1}^Kw_k\phi(x_{j,k})+b\)，再根据结果的正负号确定类别。

图 8.3：非线性核函数示例。

8.2 用于回归的 SVM

分类 SVM 的思想也可用于回归，但此时间隔的含义不同。支持向量回归（SVR）的一般形式为：

\[\begin{align} \underset{\textbf{w},b, \boldsymbol{\xi}}{\text{argmin}} \ & \frac{1}{2} ||\textbf{w}||^2+C\sum_{i=1}^I\left(\xi_i+\xi_i^* \right)\\ \text{ s.t. }& \sum_{k=1}^Kw_k\phi(x_{i,k})+b -y_i\le \epsilon+\xi_i \\ \tag{8.6} & y_i-\sum_{k=1}^Kw_k\phi(x_{i,k})-b \le \epsilon+\xi_i^* \\ &\xi_i,\xi_i^*\ge 0, \ \forall i , \end{align}\]

图 8.4 展示了其几何含义。用户指定一个 \(\epsilon\)-不敏感带，即预测函数上下各允许相应幅度的偏差；模型寻找标签 \(y_i\) 与输入 \(\textbf{x}_i\) 之间的线性关系，若使用核映射，则是在变换后的特征空间中建立线性关系。数据点落在带内时，松弛变量 \(\xi_i\) 和 \(\xi_i^*\) 都为零，其误差不计入损失；超出不敏感带的部分才受惩罚。较大的 \(\epsilon\) 会扩大容忍区间，忽略更多小误差。训练完成后，对新输入 \(\textbf{x}_j\) 的预测为 \(\sum_{k=1}^Kw_k\phi(x_{j,k})+b\)。

图 8.4：SVM 回归示意图。

概括而言，SVR 在误差不超过容忍范围（超出部分由松弛变量吸收）的前提下，尽量减小参数权重平方和 \(||\textbf{w}||^2\)。从形式上看，这与惩罚线性回归的侧重点相反：后者首先最小化预测误差，同时约束或惩罚参数权重的大小；二者本质上都在拟合程度与模型复杂度之间权衡。

本节只概述了 SVM 的几种基本形式，实际还有许多变体。用 C 和 C++ 编写的 LIBSVM 是广泛使用的参考实现，并被多种编程语言调用。有关不同 SVM 形式的更多细节，可参阅 Chang and Lin (2011)；其 2019 年 11 月的更新版本也可在线获取。

8.3 代码示例

R 中有多个软件包调用 LIBSVM，其中 e1071 是常用选择。该软件包还提供许多其他方法，包括后文将介绍的朴素贝叶斯分类器。

LIBSVM 接口要求分别传入标签和特征，因此这里复用提升树示例中定义的变量。由于 SVM 训练较慢，下面只使用训练集的前 1,000 个样本。

library(e1071)
fit_svm <- svm(y = train_label_xgb[1:1000],      # Train label
               x = train_features_xgb[1:1000,],  # Training features
               type = "eps-regression",          # SVM task type (see LIBSVM documentation)
               kernel = "radial",                # SVM kernel (or: linear, polynomial, sigmoid)
               epsilon = 0.1,                    # Width of strip for errors
               gamma = 0.5,                      # Constant in the radial kernel 
               cost = 0.1)                       # Slack variable penalisation
test_feat_short <- dplyr::select(testing_sample,features_short)
mean((predict(fit_svm, test_feat_short) - testing_sample$R1M_Usd)^2) # MSE
## [1] 0.03839085
mean(predict(fit_svm, test_feat_short) * testing_sample$R1M_Usd > 0) # Hit ratio
## [1] 0.5222197

这一结果略优于提升树示例，但这里的参数，尤其是核函数，都是任意选取的，不能据此作一般性比较。下面再看一个分类示例。

fit_svm_C <- svm(y = training_sample$R1M_Usd_C[1:1000],   # Train label
               x = training_sample[1:1000,] %>%
                   dplyr::select(features),               # Training features
               type = "C-classification",                 # SVM task type (see LIBSVM doc.)
               kernel = "sigmoid",                        # SVM kernel
               gamma = 0.5,                               # Parameter in the sigmoid kernel 
               coef0 = 0.3,                               # Parameter in the sigmoid kernel 
               cost = 0.2)                                # Slack variable penalisation
mean(predict(fit_svm_C, 
             dplyr::select(testing_sample,features)) == testing_sample$R1M_Usd_C) # Accuracy
## [1] 0.5008973

训练样本过小，加上参数选择缺乏调优，都可能导致预测准确率偏低。
